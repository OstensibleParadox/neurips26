chmod得用法
`chmod` 是 Linux/Unix 系统中用于修改文件或目录权限的命令，其名称来源于 **change mode**。

## 基本语法
```bash
chmod [选项] 权限模式 文件或目录
```

## 权限表示方式

### 1. 符号模式（相对模式）
使用字母和符号来设置权限：
```
u - 所有者(user)
g - 所属组(group)
o - 其他用户(other)
a - 所有用户(all)
```

**操作符：**
```
+ - 添加权限
- - 移除权限
= - 设置权限（覆盖原有权限）
```

**权限字符：**
```
r - 读取权限（4）
w - 写入权限（2）
x - 执行权限（1）
```

**常用示例：**
```bash
# 给所有者添加执行权限
chmod u+x file.txt

# 给所有用户添加读取权限
chmod a+r file.txt

# 设置所有者可读写执行，组用户可读执行，其他用户无权限
chmod u=rwx,g=rx,o= file.txt

# 移除组用户的写入权限
chmod g-w file.txt
```

### 2. 数字模式（绝对模式）
使用三位八进制数：
```
第一位：所有者权限
第二位：组权限  
第三位：其他用户权限
```
