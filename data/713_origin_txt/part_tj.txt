Baseline Distribution Justification. We use uniform distribu-
tion over vocabulary as the reference for three methodological
reasons. First, reproducibility: the uniform baseline requires
no external corpus, ensuring any researcher can replicate
measurements exactly. Second, domain independence: the
uniform baseline avoids privileging any particular domain’s
output distribution. Third, maximum-entropy reference: the
uniform distribution represents maximum uncertainty, so de-
viations measure the model’s constraint strength relative to
the unconstrained case.
For domain-specific applications such as auditing code assis-
tants or legal document generators, domain-adapted baselines
derived from representative prompt-response corpora would
improve diagnostic sensitivity at the cost of cross-domain
comparability.

MDL Approximation via Compression. We approximate Kol-
mogorov complexity using DEFLATE compression ratio,
following established practice in complexity measurement.
DEFLATE’s LZ77 dictionary encoding captures repetitive
structure (low MDL indicates high compressibility indicates
structured output), while its Huffman coding stage captures
character distribution entropy. Known limitations include
saturation on very long texts as the dictionary fills, sensitiv-
ity to tokenization choices, and variation across languages
due to character set differences. We mitigate saturation by
using fixed-length output windows (256 tokens) matching the
Monte Carlo simulation parameters.
Addressing KL Divergence Asymmetry. KL divergence is
asymmetric: 𝐷𝐾𝐿(𝑃 ‖𝑄) ≠ 𝐷𝐾𝐿(𝑄‖𝑃 ). This asymmetry
has substantive implications for diagnostic interpretation.
𝐷𝐾𝐿(𝑃model‖𝑃baseline) measures how surprising model
outputs are relative to baseline—high values indicate the
model assigns probability mass where baseline does not,
detecting novel or deviant behavior. 𝐷𝐾𝐿(𝑃baseline‖𝑃model)
measures how surprising baseline outputs would be under
model distribution—high values indicate the model has
“forgotten” baseline behaviors.
We select 𝐷𝐾𝐿(𝑃model‖𝑃uniform) because our diagnostic goal
is detecting deviation from maximum-entropy baseline, iden-
tifying structured behavior that stands out from uniform
randomness. This direction penalizes the model for concen-
trating probability mass on specific tokens, which is precisely
the signature of constraint-driven (non-random) output.

Self-Referential Density quantifies the degree to which model
outputs reference their own prior outputs within a session, de-
tecting the recursive reinforcement patterns characteristic of
Layer 2 failures. Where CMI measures topological centraliza-
tion (spatial structure), SRD measures temporal recurrence
(sequential structure).

between 0.3 and 0.7 indicates elevated self-reference warrant-

with high probability of imminent constraint collapse. SRD
> 1.0 indicates multi-referential cycling where the system is
generating content that simultaneously echoes multiple prior
outputs, the structural precursor to the incoherent output
observed in Yuanbao’s Phase 2 collapse.

detection. Rising SRD indicates the session is entering a re-
