# 将您的LaTeX稿件改为双盲格式的步骤

## 核心思路
您需要**创建两个文件**：
1. **主文件（匿名版）**：不含任何作者信息，用于双盲评审
2. **Title Page文件**：包含所有作者信息，单独提交

---

## 第一步：修改主文件 `main.tex`

### 1.1 注释掉或删除作者信息

找到开头的这部分：

```latex
\author{
  Lucia Yizi Zhang\thanks{Independent Researcher. Correspondence: [lucia.zhang.research@outlook.com]} \\
  \and
  Dr.\ Peng Zhao\thanks{Shanghai Lixin University of Accounting and Finance.}
}
```

**改为**（完全删除或注释掉）：

```latex
% \author{
%   Lucia Yizi Zhang\thanks{Independent Researcher. Correspondence: [lucia.zhang.research@outlook.com]} \\
%   \and
%   Dr.\ Peng Zhao\thanks{Shanghai Lixin University of Accounting and Finance.}
% }
```

或者更干脆地直接删除这几行，因为期刊要求作者信息**只出现在单独的Title Page**。

### 1.2 在文件开头添加一行（可选）

可以在 `\begin{document}` 之后、`\maketitle` 之前添加：

```latex
\author{ANONYMIZED FOR REVIEW}
```

这不是必须的，但有些期刊要求这样做。如果不确定，可以不加。

### 1.3 检查文中是否还有暴露身份的信息

搜索以下关键词：
- "Zhang"
- "Zhao"
- "our"（如果指向作者自己）
- "we have previously argued" 之类的表述

**需要修改的典型例子**：

| 原文 | 修改为 |
|------|--------|
| "as we have argued elsewhere (Zhang, 2024)" | "as has been argued elsewhere (Author, 2024)" |
| "our previous work (Zhao et al., 2023)" | "previous work (Author et al., 2023)" |
| "this paper extends Zhang's (2025) analysis" | "this paper extends prior analysis (Author, 2025)" |

**关键原则**：如果您引用自己的未发表作品，必须删除；如果引用已发表作品，用"Author"替换您的姓名。

### 1.4 确保没有致谢

检查全文是否有 `\acknowledgments` 或类似内容。如果有，**整段删除**（移到Title Page）。

---

## 第二步：创建Title Page文件

创建一个新文件 `titlepage.tex`（或 `.docx`，期刊接受混合提交）：

```latex
% titlepage.tex
\documentclass[12pt]{article}
\begin{document}

\title{\textbf{Waivers of Agency: How AI Companies Exploit the Gap Between Rules and Judgment}}

\author{
  Lucia Yizi Zhang\\
  \textit{Independent Researcher}\\
  \texttt{lucia.zhang.research@outlook.com}
  \and
  Dr.\ Peng Zhao\\
  \textit{Shanghai Lixin University of Accounting and Finance}\\
  % 如果彭博士有机构邮箱，可以在这里添加
}

\date{}

\maketitle

\vspace{2cm}

\textbf{Acknowledgments} % 如有需要
% 这里可以放致谢内容

\vspace{1cm}

\textbf{Funding} % 如有需要
% 这里可以放基金信息

\vspace{1cm}

\textbf{Competing Interests} % 与系统填写保持一致
The authors declare no competing interests.

\vspace{1cm}

\textbf{Author Contributions}
% 按CRediT标准填写
Lucia Yizi Zhang: Conceptualization, Writing - original draft, Methodology, Formal analysis. \\
Peng Zhao: Writing - review \& editing, Supervision, Validation.

\end{document}
```

如果您不想用LaTeX做Title Page，**直接用Word创建更简单**，只需包含以上信息即可。

---

## 第三步：处理自我引用

在您的BibTeX文件 `references.bib` 中，如果引用了您自己的已发表作品，**不需要修改**（因为已发表作品有公开的作者信息）。但在文中引用时，需要用不会暴露身份的格式。

例如，如果您引用自己的某篇已发表论文，可以这样做：

**原文**：
```latex
\citep{zhang2024somepaper}
```

**修改后**（仍然正常引用，因为这是公开文献，不违反双盲规则）：
```latex
\citep{zhang2024somepaper}
```

**关键**：只要您在文中的引用方式不额外说明“这是我自己的论文”，就是可以的。例如，不要写 "as we have shown (Zhang, 2024)"，直接写 "(Zhang, 2024)" 即可，审稿人不知道Zhang是谁。

## 第四步：编译检查

编译您的匿名主文件：

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

检查生成的 `main.pdf`：
- [ ] 首页没有作者姓名
- [ ] 没有作者单位
- [ ] 没有暴露身份的自我引用（如"as we argued"）
- [ ] 没有致谢
- [ ] 页码已启用

## 第五步：提交流程中的文件对应

在投稿系统（Editorial Manager）中，您需要上传：

| 系统要求 | 您上传的文件 |
|----------|-------------|
| Manuscript (anonymous) | `main.pdf`（匿名主文件） |

| Source files | `main.tex`, `references.bib`, 以及其他相关文件 |

**注意**：投稿系统在双盲模式下，只有编辑能看到Title Page，审稿人看不到。
