可以在rm命令中使用占位符吗
是的，在 `rm` 命令中可以使用占位符，通常是通过通配符（wildcard characters）实现的。不过需要注意，在 `rm` 中使用通配符需要特别小心，因为误删可能导致数据丢失。

## 常用通配符占位符：

### 1. **星号 `*`** - 匹配任意数量字符
```bash
# 删除所有 .txt 文件
rm *.txt

# 删除以 test 开头的所有文件
rm test*

# 删除包含 test 的所有文件
rm *test*

# 删除所有文件（危险！）
rm *
```

### 2. **问号 `?`** - 匹配单个字符
```bash
# 删除 file1.txt, file2.txt, file3.txt 等
rm file?.txt

# 删除 fileA.txt, fileB.txt 等（仅一位字符）
rm file?.txt
```

### 3. **方括号 `[]`** - 匹配指定范围的字符
```bash
# 删除 file1.txt 到 file9.txt
rm file[1-9].txt

# 删除 filea.txt, fileb.txt, filec.txt
rm file[a-c].txt

# 删除 file1.txt, file2.txt, file3.txt
rm file[123].txt
```

## 安全使用建议：

### 1. **先使用 `ls` 预览**
```bash
# 先查看匹配的文件
ls *.txt
# 确认无误后再删除
rm *.txt
```

### 2. **使用交互模式 `-i`**
```bash
rm -i *.txt
# 对每个匹配的文件都会询问是否删除
```

### 3. **使用详细模式 `-v`**
```bash
rm -v *.txt
# 显示正在删除的每个文件
```

### 4. **使用 find 命令更精确控制**
```bash
# 找到并删除7天前的 .log 文件
find . -name "*.log" -mtime +7 -exec rm {} \;

# 或者先查看
find . -name "*.log" -mtime +7
```

## 进阶技巧：

### 花括号扩展 `{}`
```bash
# 删除多个特定文件
rm file{1,3,5}.txt
# 等同于 rm file1.txt file3.txt file5.txt

# 范围扩展
rm file{1..10}.txt
# 等同于 rm file1.txt file2.txt ... file10.txt
```

### 变量结合使用
```bash
# 使用变量
prefix="backup_"
rm "${prefix}"*.tar.gz
```

## ⚠️ 重要警告：

1. **`rm -rf *` 极其危险** - 会递归删除当前目录所有文件
2. **通配符可能匹配意外文件** - 特别是在有空格或特殊字符的文件名时
3. **考虑使用 trash-cli** - 将文件移到回收站而不是直接删除
   ```bash
   # 安装
   sudo apt install trash-cli  # Ubuntu/Debian
   
   # 使用
