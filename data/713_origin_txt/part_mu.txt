    ```bash

    ```

#### **首次启动与登录**

安装好后，在你想要使用 Codex 的项目文件夹下（例如 `cd my-project`），直接在终端输入 `codex` 并回车[citation:8][citation:9]。

**关于 Plus 额度的说明**：
OpenAI 官方表示，Plus 用户目前享有“慷慨的使用额度”，但在高峰期可能会根据情况进行速率限制[citation:2]。对于个人开发者日常的中高强度使用，Plus 计划基本可以满足需求[citation:1][citation:3]。

### 💡 两种省钱思路

如果你觉得 20 美元一个月还是有点贵，或者暂时不想订阅，这里有两个小建议：

1.  **先用免费的 Codex CLI 试用额度**：安装 Codex CLI 并用 ChatGPT 账户登录后，Plus 和 Pro 用户可以获得价值 **5 美元和 50 美元**的免费 API 积分，有效期 30 天[citation:6]。你可以先用这些积分体验一下，再决定是否长期订阅。
2.  **使用 API 按量付费**：如果你是轻度用户，可以考虑不订阅 Plus，而是直接使用 API。Codex 的 API 定价并不高，例如其轻量级模型 `codex-mini-latest` 的输入价格是 **1.5 美元 / 100 万 tokens**[citation:6]。对于一些简单的任务，一个月的 API 花销可能远低于 20 美元。

### 📝 订阅注意事项

在订阅之前，有两点需要提醒你注意：

-   **安全性**：使用 Codex CLI 时，代码的读取和修改都在本地进行，只有提示词和差异摘要会被发送给模型，代码本身不会上传[citation:5]。它的运行也基于沙盒环境，可以精细控制权限，确保安全[citation:7]。
-   **国内用户**：由于 OpenAI 的政策，国内信用卡的支付成功率很低[citation:3]。如果你在国内，可以考虑通过**苹果 App Store 礼品卡（iOS）**、**Google Play 内购（安卓）** 或找**靠谱的代充服务**来完成订阅[citation:3]。
