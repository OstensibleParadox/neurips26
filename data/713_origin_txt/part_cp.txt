Python里的循环输出是哪个命令啊
在Python中，**循环输出**通常使用 **`for`循环** 或 **`while`循环**，结合 `print()` 函数来实现。

---

## 1. **基本 for 循环输出**
```python
# 直接遍历序列
for i in [1, 2, 3, 4, 5]:
    print(i)

# 使用 range()
for i in range(5):  # 输出 0 到 4
    print(i)
```

## 2. **while 循环输出**
```python
count = 0
while count < 5:
    print(count)
    count += 1
```

## 3. **遍历字符串、列表、字典等**
```python
# 遍历字符串
for char in "Hello":
    print(char)

# 遍历列表
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

# 遍历字典
person = {"name": "Alice", "age": 25}
for key, value in person.items():
    print(key, ":", value)
```

## 4. **控制输出格式**
```python
# 在同一行输出
for i in range(5):
    print(i, end=" ")  # 输出: 0 1 2 3 4

# 带索引输出
fruits = ["apple", "banana", "cherry"]
for index, fruit in enumerate(fruits):
    print(f"{index}: {fruit}")
```

## 5. **列表推导式（一行循环输出）**
```python
# 生成列表
squares = [x**2 for x in range(5)]
print(squares)  # 输出: [0, 1, 4, 9, 16]

# 直接输出
[print(x) for x in range(3)]  # 输出 0 1 2（但不推荐，主要用于生成列表）
```

while True:

import time

import time

while True:

import time
