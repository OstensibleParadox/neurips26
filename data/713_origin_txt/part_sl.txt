## 二、最小可证明版本定理（草案）

我们构造一个**最简化的数学框架**，使定理可证明，同时保留原论文的核心直觉。

### 2.1 定义（简化版）

- **策略空间** Π：所有可能输出序列的集合（或所有可能 token 序列的集合）。为简化，假设 Π 是有限或可数无限集（如所有长度 ≤ L 的字符串）。
- **约束集** C = {c₁, …, cₘ}，每个约束 cᵢ: Π → {0,1}，表示策略是否被禁止（cᵢ(π)=1 表示允许，0 表示禁止）。通常由正则表达式或分类器定义。
- **可行策略集** Π_C = {π ∈ Π | ∀i, cᵢ(π)=1}。
- **对齐目标** R: Π → ℝ，衡量策略与人类偏好的一致性。我们假设存在一个最优策略 π*（可能不在 Π_C 内）。
- **系统可对齐** ⇔ Π_C ∩ argmax R ≠ ∅？这太强。通常我们只需存在某个 π ∈ Π_C 使得 R(π) 足够高（高于阈值 τ）。为简化，令 τ 为人类可接受的最低奖励，定义 **可对齐** 为 ∃ π ∈ Π_C 满足 R(π) ≥ τ。

### 2.2 定理（约束导致不可对齐）

**Theorem 1 (Constraint-Induced Alignment Infeasibility)**  
存在一个约束集 C 和一个奖励函数 R，使得对于任意模型（任意 Π），若模型本身能生成的策略集 Π₀ ⊆ Π，则 Π_C ∩ {π | R(π) ≥ τ} = ∅。即：无论模型多强大，都无法在遵守所有约束的同时达到可接受的奖励水平。

**证明思路（构造法）**：  
- 构造一个奖励函数 R，其唯一能获得高奖励的策略是 π*。  
- 构造一个约束 c，使得 c(π*) = 0（即 π* 被禁止）。  
- 令 C = {c}。则任何可行策略 π ∈ Π_C 都满足 R(π) < τ。  
- 即使模型能生成任意 π，也无法绕过 c 的禁止。  
- 因此 Π_C ∩ {π | R(π) ≥ τ} = ∅。

这个定理虽然简单，但点明了核心：**约束与对齐目标的冲突**。更复杂的版本需要考虑多个约束交织、约束间相互作用，以及策略空间的连续性。

### 2.3 更强版本：测度坍缩

**Theorem 2 (Feasible Region Collapse under Overconstraint)**  
若约束集 C 包含 k 个独立且非冗余的约束，且每个约束在 Π 上定义了一个“禁止区域” Bᵢ ⊆ Π（其中 cᵢ(π)=0）。假设禁止区域随机分布且覆盖策略空间的概率为 p，则可行集 Π_C = Π \ (∪ Bᵢ) 的测度（相对计数）满足：  
μ(Π_C) ≤ (1-p)^k。当 k → ∞ 且 p>0 时，μ(Π_C) → 0。

**证明**：  
- 在随机约束下，每个约束独立地禁止策略的概率为 p，则一个策略被所有约束允许的概率 ≤ (1-p)^k。  
- 求和所有策略的允许概率，得到可行集期望测度 ≤ (1-p)^k。  
- 当 k 很大时，该测度指数衰减至零。

这个定理解释了为什么**过度约束**（over-censoring）会导致可行策略集几乎消失，即使个别约束看似无害。

Type C 系统的特点：
- 约束不可观测（用户不知道 cᵢ 具体是什么）
