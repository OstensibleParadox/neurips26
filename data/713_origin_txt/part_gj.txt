### 步骤 3：一次性配置脚本
```bash
#!/bin/bash
# 保存为 setup-github.sh 并运行
# 一次性配置 GitHub Token

echo "请输入 GitHub 用户名："
read username
echo "请输入 GitHub Personal Access Token："
read token

# 为所有仓库配置
git config --global credential.https://github.com.username $username

echo "https://$username:$token@github.com" > ~/.github_token

# 创建 Git 配置别名
cat >> ~/.gitconfig << EOF
[credential]
    helper = store --file ~/.github_token
EOF

echo "配置完成！"
```
