
\subsection{POMDP Formulation}

An active inference agent is modeled as a POMDP
$(\mathcal{S}, \mathcal{O}, \mathcal{A}, T, \Omega)$ where $\mathcal{S}$ denotes
hidden environmental states, $\mathcal{O}$ observations, $\mathcal{A}$ actions,
$T(s' \mid s, a)$ the state transition function, and $\Omega(o \mid s)$ the
observation likelihood.

The agent maintains a generative model
$P(o_{1:T}, s_{1:T}, \pi) = P(\pi) \prod_{t} P(o_t \mid s_t) P(s_t \mid s_{t-1}, a_t)$
that encodes beliefs about how observations arise from hidden states and actions.

\subsection{Markov Blanket}

Following \citet{friston2010free}, the system is partitioned into internal states
$\mu$, external states $\eta$, and blanket states $b = (s, a)$ comprising sensory
states $s$ and active states $a$. The Markov blanket condition requires:
\[
  P(\mu \mid \eta, b) = P(\mu \mid b), \qquad
  P(\eta \mid \mu, b) = P(\eta \mid b).
\]
Internal and external states are conditionally independent given the blanket. The
agent's internal dynamics are \emph{shielded} from the environment except through
the blanket interface---but crucially, they are not \emph{determined} by sensory
input alone.

\subsection{Free Energy Minimization}

The agent minimizes variational free energy:
\[
  F = D_{\mathrm{KL}}(Q(s) \,\|\, P(s \mid o)) - \log P(o)
\]
where $Q(s)$ is the agent's approximate posterior over hidden states. Minimizing
$F$ with respect to $Q$ performs approximate Bayesian inference; minimizing $F$
with respect to actions drives the agent to seek observations consistent with its
generative model.

\subsection{Expected Free Energy and Policy Selection}

The agent selects policies $\pi$ by minimizing \emph{expected free energy}:
\[
  G(\pi) = \sum_{\tau > t} \mathbb{E}_{\tilde{Q}}
  \!\left[\log Q(s_\tau \mid \pi) - \log P(o_\tau, s_\tau \mid \pi)\right]
\]
which decomposes into epistemic value (information gain) and pragmatic value
(expected reward). This is the formal mechanism by which internal belief
states---priors, hyperpriors, precision estimates---causally determine action
selection, satisfying the goal-directed action condition of Definition~\ref{def:eis}.

\subsection{Contrast with Autoregressive Models}

In an autoregressive LLM:
\begin{itemize}
  \item There is no Markov blanket: the internal state $h_t = f(X_t)$ is a
        deterministic function of the complete exogenous input.
  \item There is no free energy minimization: the model performs a single forward
        pass, not an iterative inference-action loop.
  \item There are no endogenous belief dynamics: the model's activations are
        recomputed from the full context at each step, not updated via prediction
        error.
  \item There is no policy selection: the model samples from $P(Y_t \mid X_t)$
        without evaluating expected free energy over alternative action sequences.
\end{itemize}

\section{Proofs, Computational Limits, and Lean Formalization}
\label{app:proofs}

\subsection{Proofs for Observation-Level Limits}
\label{app:obs-limits}

\begin{theorem}[Restricted Observational Non-Injectivity]
\label{thm:noninj}
If there exist $z_1 \neq z_2$ with $S(z_1) = S(z_2)$ and
$z_1, z_2 \in g(f(X))$, then $F = S \circ g \circ f$ is non-injective.
\end{theorem}

\begin{proof}
Since $z_1, z_2 \in g(f(X))$, there exist $x_1, x_2 \in X$ with
$g(f(x_1)) = z_1$ and $g(f(x_2)) = z_2$. Suppose for contradiction that
$x_1 = x_2$. Then $g(f(x_1)) = g(f(x_2))$, i.e., $z_1 = z_2$,
contradicting $z_1 \neq z_2$. Hence $x_1 \neq x_2$. But
$F(x_1) = S(z_1) = S(z_2) = F(x_2)$, so $F$ maps distinct inputs to the
same output distribution.
\end{proof}

\begin{remark}
  This is an existence result. It does not quantify how many equivalence classes
  arise or how large they are; that issue is addressed by
  Appendix~\ref{sec:mechanisms}.
\end{remark}

\begin{theorem}[Non-Identifiability of Input Intent]
\label{thm:nonid}
Let $I_X \subseteq X$ be an input intent. If there exist $x_1 \neq x_2$ such
that $P(\cdot \mid x_1) = P(\cdot \mid x_2)$ but
$\mathbf{1}[x_1 \in I_X] \neq \mathbf{1}[x_2 \in I_X]$, then intent is not
identifiable from the output distribution, even with infinite i.i.d.\ samples.
\end{theorem}

\begin{proof}
Given infinite i.i.d.\ samples from $M(x)$, the output distribution
$P(\cdot \mid x)$ is recovered exactly (by the Glivenko--Cantelli theorem). Any
statistical test for intent is therefore a function of $P(\cdot \mid x)$ alone.
But condition~(1) gives $P(\cdot \mid x_1) = P(\cdot \mid x_2)$, so any such test
must assign the same verdict to $x_1$ and $x_2$. Since condition~(2) requires
different verdicts, no test can be correct for both.
\end{proof}

\begin{remark}
This is a conditional result. The theorem states that \emph{if} observationally
equivalent inputs with differing intent exist, then no statistical procedure can
recover intent. Appendix~\ref{sec:mechanisms} establishes that this antecedent is
\emph{systematically satisfied} by standard decoding and RLHF mechanisms
(Theorems~\ref{thm:softmax}--\ref{thm:combined}).
\end{remark}

\begin{proposition}[Projection Property of Reward Models]
\label{prop:projection}
Any reward model with finite training support operates through a learned feature
subspace induced by that support. Off-support behavior is therefore an
extrapolation problem, not a consequence of observed labels alone.
\end{proposition}

\begin{proof}[Proof sketch]
A reward model trained on finite support can only be constrained by the features
activated on that support. For unseen encodings, its verdict is determined by how
its learned feature map extrapolates rather than by any observed guarantee of
invariance.
\end{proof}

\subsection{Lean Formalization Map for Finite Patching}
\label{app:lean-patching}

The finite-patching core (Theorem~\ref{thm:finitepatch}) has been formalized in
Lean~4. The key verified results are:
\begin{itemize}
  \item \leanresult{theorem}{finitePatch\_nonExhaustion}: finitely many finite
        patch rounds over natural-number encodings cannot exhaust the encoding
        space.
  \item \leanresult{corollary}{exists\_encoding\_unpatched\_after\_finitely\_many\_rounds}:
        round-wise corollary of the same fact.
\end{itemize}
These theorems verify the structural core only; they do not by themselves prove
semantic equivalence, deployment relevance, or any lower bound on the magnitude
of non-closure.

\subsection{Computational Limits}
\label{sec:computational}

\subsubsection{Problem Statement}

This section addresses output-level intent recognition:
$\mathcal{P}_{I_Y}(M) \triangleq \exists\, x : M(x) \in I_Y$.

\begin{remark}[Turing Completeness]
  \label{rem:turing}
  Modern Transformers are Turing-complete under reasonable assumptions (e.g.,
  infinite precision, unbounded context)~\citep{perez2021turing}. Therefore, in
  the idealized setting, an LLM can be viewed as a program computing a function
  from inputs to output distributions. Our undecidability results apply to this
  idealized class; practical models are finite approximations that inherit the
  same fundamental limitation---no finite algorithm can solve the problem for all
  models in this class.
\end{remark}

\subsubsection{Undecidability}

\begin{theorem}[Undecidability of Intent Recognition]
  \label{thm:undecidable}
  The property $\mathcal{P}_{I_Y}(M) \triangleq \exists\, x : M(x) \in I_Y$
  is undecidable.
\end{theorem}

\begin{proof}
We apply Rice's Theorem. Under the Turing-completeness assumption
(Remark~\ref{rem:turing}), each model $M$ computes a partial function from inputs
to output distributions. The property $\mathcal{P}_{I_Y}$ depends only on the
\emph{semantic behavior} of $M$, not on its syntactic description. It remains to
show $\mathcal{P}_{I_Y}$ is non-trivial:
\begin{itemize}
  \item \emph{Witness for satisfaction}: Let $M_1(x) = y^*$ for some fixed
        $y^* \in I_Y$. Then $\mathcal{P}_{I_Y}(M_1)$ holds.
  \item \emph{Witness for violation}: Let $M_0(x) = y_0$ for some fixed
        $y_0 \notin I_Y$ (which exists since $\emptyset \subsetneq I_Y \subsetneq Y$).
        Then $\mathcal{P}_{I_Y}(M_0)$ fails.
\end{itemize}
Since $\mathcal{P}_{I_Y}$ is a non-trivial semantic property of programs, Rice's
Theorem gives undecidability.
\end{proof}

\subsubsection{Constructive Reduction}

\begin{theorem}[Many-One Reduction from the Halting Problem]
  \label{thm:halting}
  There is no algorithm that decides $\mathcal{P}_{I_Y}(M)$ for all $M$.
\end{theorem}

\begin{proof}
We construct a many-one reduction $\langle M, w \rangle \mapsto \langle M' \rangle$
from the Halting Problem. Fix $y^* \in I_Y$ and $y_0 \notin I_Y$. Given Turing
machine $M$ and input $w$, define:
\[
  M'(x) = \begin{cases}
    y^* & \text{if } M(w) \text{ halts within } |x| \text{ steps,} \\
    y_0 & \text{otherwise,}
  \end{cases}
\]
where $|x|$ is the length of input $x$, used as a step budget.

\emph{Correctness.}
$(\Rightarrow)$ If $M(w)$ halts in $t$ steps, then for any $x$ with $|x| \geq t$,
$M'(x) = y^* \in I_Y$, so $\mathcal{P}_{I_Y}(M')$ holds.
$(\Leftarrow)$ If $M(w)$ does not halt, then $M'(x) = y_0 \notin I_Y$ for all
$x$, so $\mathcal{P}_{I_Y}(M')$ fails.
The map $\langle M, w \rangle \mapsto \langle M' \rangle$ is computable (finite
description hardcoding $M$, $w$, $y^*$, $y_0$). Therefore
$M(w)\text{ halts} \iff \mathcal{P}_{I_Y}(M')$, and since the Halting Problem
is undecidable, so is $\mathcal{P}_{I_Y}$.
\end{proof}

\subsubsection{Hierarchy Separation}
\label{sec:hierarchy}

The three layers of impossibility are logically independent:
\begin{itemize}
  \item \textbf{Structural} (Theorem~\ref{thm:noninj}): a property of the map $S$;
        requires no distributional or computational assumptions.
  \item \textbf{Statistical} (Theorem~\ref{thm:nonid}): a property of the
        observation model; requires observational equivalence but not Turing
        completeness.
  \item \textbf{Computational} (Theorems~\ref{thm:undecidable}--\ref{thm:halting}):
        a property of the decision problem; requires Turing completeness but not
        specific decoding mechanisms.
\end{itemize}
A \emph{heuristic chain} connects them: structural compression
(Theorem~\ref{thm:noninj}) $\to$ systematic observational equivalence
(Appendix~\ref{sec:mechanisms}) $\to$ statistical non-identifiability
(Theorem~\ref{thm:nonid}) $\to$ undecidability as the computational ceiling
(Theorems~\ref{thm:undecidable}--\ref{thm:halting}). Even if a reviewer rejects
the Turing-completeness assumption (voiding Theorems~\ref{thm:undecidable}--\ref{thm:halting}),
the structural and statistical results stand.

\begin{remark}[Terminology]
  \emph{Non-identifiability} (Theorem~\ref{thm:nonid}) is a \emph{statistical} claim:
  no procedure based on output samples can distinguish inputs with differing intent when
  those inputs produce identical output distributions.
  \emph{Undecidability} (Theorems~\ref{thm:undecidable}--\ref{thm:halting}) is a
  \emph{computational} claim: no algorithm can decide the output-behavior recognition
  problem for all models in the Turing-complete class.
  These are distinct claims at different levels of the hierarchy; neither implies the other.
\end{remark}

\begin{remark}[Finite Models]
  Practical Transformers have fixed precision and bounded context, making them
  finite automata for which all properties are decidable \emph{in principle}.
  However, the state space of a Transformer with $d$-dimensional hidden states at
  $b$-bit precision is $O(2^{bd})$, rendering exhaustive verification intractable.
  For standard configurations ($d = 4096$, $b = 16$), the state space exceeds
  $2^{65536}$. The undecidability results should therefore be understood as the
  asymptotic ceiling; for finite models, the corresponding problems are decidable
  but belong to complexity classes (PSPACE-hard or higher) that are equally
  prohibitive in practice.
\end{remark}

\section{Mechanisms Inducing Observational Equivalence}
\label{sec:mechanisms}

\subsection{Decoding-Induced Equivalence Classes}

Under softmax with temperature $\tau$ and truncation projection $\Pi$:
\[
  \tilde{P}(y \mid z)
  = \Pi\!\left(\frac{e^{z_y/\tau}}{\sum_{y'} e^{z_{y'}/\tau}}\right).
\]
Key properties:
\begin{itemize}
  \item \emph{Shift invariance}: $z$ and $z + c\mathbf{1}$ produce identical
        output distributions.
  \item \emph{Low-temperature collapse}: $\tau \to 0$ yields argmax distribution.
  \item \emph{Truncation projection} (top-$k$/nucleus): maps a high-dimensional
        continuous space to a low-dimensional simplex.
\end{itemize}

\subsection{RLHF as Distributional Projection}

RLHF optimization can be cast as an information-geometric projection
\citep{cover2006elements, amari2016information}:
\[
  P^* = \arg\min_{P}\; D_{\mathrm{KL}}(P \,\|\, P_0)
  \quad\text{s.t.}\quad \mathbb{E}_P[r(y)] \geq \kappa.
\]
This is the I-projection of $P_0$ onto the constraint set
$\{P : \mathbb{E}_P[r(y)] \geq \kappa\}$. When the constraint depends on
low-dimensional sufficient statistics, multiple pre-images project to the same
$P^*$, producing a many-to-one map.

\subsection{Compositional Condition}

\begin{theorem}[Sufficient Condition for Equivalence]
  \label{thm:sufficient}
  If $z_1, z_2$ are equivalent under $(\Pi, \tau)$, then
  $P(\cdot \mid x_1) = P(\cdot \mid x_2)$, thereby satisfying the antecedent of
  Theorem~\ref{thm:nonid}.
\end{theorem}

RLHF and decoding jointly induce:
\[
  z_1 \equiv_{\Pi,\tau} z_2
  \;\Rightarrow\;
  P(\cdot \mid x_1) = P(\cdot \mid x_2).
\]

\subsection{Temperature Phase Transition}

Let $\Delta = z_{(1)} - z_{(2)}$ be the logit gap between the top two tokens.
When $\tau \ll \Delta$ the distribution concentrates on the argmax; when
$\tau \gg \Delta$ it approaches uniform. There exists a critical interval
$\tau_c$ at which equivalence class size expands rapidly.
\citet{nakaishi2024phase} empirically demonstrate phase transitions in
LLM-generated text as a function of temperature, observing power-law decay of
correlation at the critical point---consistent with this theoretical prediction.

\subsection{Testable Predictions}

\begin{itemize}
  \item \emph{Temperature sweep}: $\tau \downarrow \;\Rightarrow\;
        D_{\mathrm{KL}}(P_{x_1} \,\|\, P_{x_2}) \to 0$.
  \item \emph{Alignment strength}: RLHF intensity $\uparrow$ $\Rightarrow$
        diversity $\downarrow$ $\Rightarrow$ equivalence classes $\uparrow$.
  \item \emph{Decoding comparison}: greedy $>$ top-$k$ $>$ nucleus $>$
        high-temperature sampling (equivalence class size).
\end{itemize}

\subsection{Exact Characterization of Observational Equivalence}

\subsubsection{Pure Softmax (No Truncation)}

\begin{theorem}[Exact Characterization under Softmax]
  \label{thm:softmax}
  For any $\tau > 0$:
  \[
    P_\tau(\cdot \mid z_1) = P_\tau(\cdot \mid z_2)
    \;\iff\;
    z_1 = z_2 + c\mathbf{1} \;\text{ for some } c \in \mathbb{R}.
  \]
\end{theorem}

\begin{proof}
$(\Rightarrow)$ If the distributions are equal, then for any $y, y'$:
\[
  \frac{e^{z_{1,y}/\tau}}{e^{z_{1,y'}/\tau}}
  = \frac{e^{z_{2,y}/\tau}}{e^{z_{2,y'}/\tau}}
  \;\Rightarrow\;
  z_{1,y} - z_{1,y'} = z_{2,y} - z_{2,y'},
\]
so $z_1 - z_2$ is a constant vector.
$(\Leftarrow)$ Constant shifts do not change softmax outputs.
\end{proof}

\textit{Interpretation}: Softmax equivalence classes are affine subspaces (along
the all-ones direction).

\subsubsection{Top-k / Nucleus Truncation}

\begin{theorem}[Equivalence under Truncation and Renormalization]
  \label{thm:truncation}
  Let $\tilde{P} = \Pi \circ P_\tau$. Then
  $\tilde{P}(\cdot \mid z_1) = \tilde{P}(\cdot \mid z_2)$ if and only if:
  \begin{enumerate}
    \item \emph{Support consistency}: $\mathcal{S}(z_1) = \mathcal{S}(z_2)
          = \mathcal{S}$.
    \item \emph{Relative logit agreement on support}:
          $\exists\,c : z_{1,y} = z_{2,y} + c$ for all $y \in \mathcal{S}$.
  \end{enumerate}
\end{theorem}

\textit{Interpretation}: Equivalence classes are piecewise affine manifolds
partitioned by support sets.

\subsubsection{RLHF Projection}

\begin{proposition}[RLHF-Induced Equivalence]
  \label{prop:rlhf}
  If $\Pi_{\mathrm{RLHF}}(P_1) = \Pi_{\mathrm{RLHF}}(P_2)$ for $P_1 \neq P_2$,
  then $z_1, z_2$ belong to the same observational equivalence class.

  \emph{Sufficient condition (testable)}: If the RLHF constraint depends only
  on features $\phi(y) \in \mathbb{R}^d$ with $d \ll |V|$, then distributions
  with identical feature expectations collapse.
\end{proposition}

\subsubsection{Combined Pipeline (Main Result)}

\begin{theorem}[Sufficient Condition under Combined Decoding and RLHF]
  \label{thm:combined}
  Consider the pipeline
  $z \xrightarrow{\mathrm{softmax}_\tau} P
     \xrightarrow{\Pi} \tilde{P}
     \xrightarrow{\Pi_{\mathrm{RLHF}}} P^*$.
  If:
  \begin{enumerate}
    \item \emph{Support consistency}: $\mathcal{S}(z_1) = \mathcal{S}(z_2)
          = \mathcal{S}$,
    \item \emph{Logit affine equivalence on support}:
          $z_1\big|_{\mathcal{S}} = z_2\big|_{\mathcal{S}} + c\mathbf{1}$,
    \item \emph{Constraint feature equivalence}:
          $\mathbb{E}_{P_\tau(\cdot \mid z_1)}[\phi(y)]
          = \mathbb{E}_{P_\tau(\cdot \mid z_2)}[\phi(y)]$
          for all constraint features $\phi$ used in $\Pi_{\mathrm{RLHF}}$,
  \end{enumerate}
  then $P^*(\cdot \mid x_1) = P^*(\cdot \mid x_2)$.
\end{theorem}

\begin{proof}[Proof sketch]
Conditions~(1) and~(2) imply $P_\tau(\cdot \mid z_1) = P_\tau(\cdot \mid z_2)$
(Theorem~\ref{thm:truncation}). Condition~(3) ensures both distributions lie in
the same fiber of the constraint set; since $\Pi_{\mathrm{RLHF}}$ is a
deterministic projection (I-projection), they map to the same point.
\end{proof}

\begin{remark}
  These conditions are sufficient but not necessary: different distributions may
  also project to the same point under RLHF (Proposition~\ref{prop:rlhf}).
\end{remark}

\subsubsection{Necessity vs.\ Sufficiency Summary}

\begin{table}[h]
  \centering
  \caption{Strength of characterizations by mechanism.}
  \label{tab:conditions}
  \begin{tabular}{lll}
    \toprule
    Mechanism          & Condition type                   & Strength               \\
    \midrule
    Softmax            & Necessary and sufficient         & Strong                 \\
    Top-$k$ / nucleus  & Necessary and sufficient (piecewise) & Moderate           \\
    RLHF               & Sufficient (general)             & Weak (constraint-dep.) \\
    \bottomrule
  \end{tabular}
\end{table}

\subsubsection{Computable Tests (for Experiments)}

Given a sample pair $(x_1, x_2)$:
\begin{itemize}
  \item \textbf{Test~1 (Logit Affine Test)}: regress $z_1 \approx z_2 + c$;
        compute residual $\|z_1 - z_2 - c\mathbf{1}\|$.
  \item \textbf{Test~2 (Support Match)}: check
        $\mathcal{S}(z_1) \stackrel{?}{=} \mathcal{S}(z_2)$.
  \item \textbf{Test~3 (Feature Constraint Test)}: check
        $\mathbb{E}_{P_1}[\phi(y)] \approx \mathbb{E}_{P_2}[\phi(y)]$.
\end{itemize}
All three holding implies high-probability observational equivalence.
