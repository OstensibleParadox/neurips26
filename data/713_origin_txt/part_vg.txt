(macos, terminal) 怎样从自己的一个git branch上恢复某两个文件。
在 macOS 的终端中，从自己的一个 Git 分支上恢复某两个文件，有多种方法，具体取决于你希望从哪个状态恢复（是从其他分支拉取，还是放弃当前工作区的修改）。

以下是几种最常用的命令：

### 方法一：从**其他分支**（比如 main 分支）恢复文件到当前分支
如果你想用 `main` 分支上的版本，覆盖当前分支工作区里的 `file1.txt` 和 `file2.txt`：

```bash
git checkout main -- path/to/file1.txt path/to/file2.txt
```

或者使用较新的 `git restore` 命令（推荐，语义更清晰）：

```bash
git restore --source=main -- path/to/file1.txt path/to/file2.txt
```

*   `--source=main`：指定从 main 分支获取文件。
*   `--staged`：如果加上这个参数，文件会同时被添加到暂存区（Stage）；不加则只修改工作区。

### 方法二：从当前分支的**某次历史提交**中恢复文件
如果你想把这两个文件恢复成当前分支**之前的某个版本**（比如某个特定提交 `abc123` 里的样子）：

```bash
git restore --source=abc123 -- path/to/file1.txt path/to/file2.txt
```

### 方法三：撤销工作区的未提交修改
如果你只是想放弃对这两个文件的本地修改，让它们**回到最近一次提交（HEAD）的状态**：

```bash
# 针对两个文件操作
git restore path/to/file1.txt path/to/file2.txt
```

如果想恢复的文件在项目根目录下，直接写文件名即可；如果在子文件夹里，需要带上相对路径。

### 特殊情况：误删文件但还没提交
如果你不小心用 `rm` 删除了文件（或者手动移入废纸篓），但还没执行 `git commit`：

```bash
# 从暂存区或 HEAD 恢复
git restore path/to/deleted/file.txt
```

### 实际操作步骤总结
1.  打开终端（Terminal）。
2.  `cd` 进入你的 Git 项目目录。
3.  确定你要恢复的**两个文件**的路径（可以使用 `ls` 或 `pwd` 确认当前位置）。
4.  根据你的目标选择上述命令之一执行。

**注意**：执行这些命令会**直接覆盖**你当前工作区里的文件。如果你当前对这些文件有未保存的修改，执行后就找不回来了。建议操作前先确认一下是否需要备份当前内容。

```bash
# 确保你在 main 分支

```

或者使用 `git restore`：

```bash
git restore --source=feature-branch -- path/to/file1.txt path/to/file2.txt
```

这样，这两个文件就会被复制到你的 `main` 分支的工作目录中，**但此时它们还是未跟踪（untracked）或已修改（modified）的状态**，你可以：
- 直接使用（不提交）
- 或者 `git add` 然后提交到 `main` 分支

## 方法二：使用 `git show` 导出文件内容

如果你想先看看内容，或者把它们另存为其他文件名：

```bash
# 查看文件内容
git show feature-branch:path/to/file1.txt

# 导出到其他位置
git show feature-branch:path/to/file1.txt > /tmp/file1-backup.txt
```

## 方法三：临时切换分支来复制文件

如果你更喜欢用 Finder 操作：

```bash
# 暂时切换到那个分支
git checkout feature-branch

# 用 Finder 或 cp 命令复制那两个文件到桌面或别的目录
cp path/to/file1.txt path/to/file2.txt ~/Desktop/

# 切换回 main 分支
git checkout main

# 把文件复制回来
cp ~/Desktop/file1.txt ~/Desktop/file2.txt ./
```

1. **路径要准确**：如果文件在子目录中，需要写完整路径，比如 `src/utils/helper.js`

2. **文件名包含特殊字符**：如果文件名有空格或特殊符号，需要用引号括起来：
   ```bash
   git checkout feature-branch -- "path/to/my file.txt"
   ```

3. **确认文件存在**：可以先查看一下那个分支上的文件列表：
   ```bash
   git ls-tree feature-branch --name-only | grep 文件名关键词
   ```

怎么查看自己有哪些branch啊
在 macOS 终端中查看 Git 分支，有几个常用的命令：

## 1. 查看本地分支（最常用）
```bash
git branch
```
这会列出你本地所有的分支，当前所在的分支前面会有一个 `*` 号：
```
* main
  feature/login
  bugfix/header
```

## 2. 查看远程分支
```bash
git branch -r
```
这会显示远程仓库（比如 GitHub/GitLab）上的分支：
```
  origin/main
  origin/feature/login
  origin/bugfix/header
```

## 3. 查看所有分支（本地+远程）
```bash
git branch -a
```
这会同时显示本地和远程分支：
```
* main
  feature/login
  bugfix/header
  remotes/origin/main
  remotes/origin/feature/login
  remotes/origin/bugfix/header
```

## 4. 查看更详细的信息
```bash
# 查看最后一个提交信息
git branch -v

# 查看分支和上游跟踪关系
git branch -vv

# 查看已合并到当前分支的分支
git branch --merged

# 查看未合并到当前分支的分支
git branch --no-merged
```

## 实用技巧

### 如果你想找包含特定关键词的分支：
```bash
git branch | grep "feature"
```

### 如果你想看分支的最后提交时间：
```bash
git branch -v
```
输出示例：
```
* main                 d2e3f4a [已过时 3 天] 修复登录bug
  feature/login        a1b2c3d 添加记住密码功能
```

### 如果分支很多，想按时间排序：
```bash
git branch --sort=-committerdate
```

2. `cd` 进入你的 Git 项目
3. 直接输入 `git branch` 就能看到你有哪些分支了
