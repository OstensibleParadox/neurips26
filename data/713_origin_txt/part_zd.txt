---

## 1. 连接被拒绝的错误类型

### ① `Connection refused`（连接被拒绝）
```
ssh: connect to host xxx.xxx.xxx.xxx port 22: Connection refused
```
**含义**：目标机器的 22 端口没有监听 SSH 服务。
**原因**：
- SSH 服务未启动
- 防火墙阻止了 22 端口
- SSH 服务监听在其他端口

### ② `Permission denied`（权限拒绝）
```
Permission denied (publickey,password).
```
**含义**：服务器收到了连接，但拒绝了你提供的认证信息。
**原因**：
- 用户名错误
- 密码错误
- SSH 密钥未添加
- 服务器禁用了密码登录，只允许密钥登录

### ③ `Connection timed out`（连接超时）
```
ssh: connect to host xxx.xxx.xxx.xxx port 22: Connection timed out
```
**含义**：客户端发起的连接请求没有得到任何响应。
**原因**：
- 网络不通
- 防火墙直接丢弃了数据包（而非返回拒绝）
- 服务器 IP 地址错误

### ④ `Host key verification failed`
```
Host key verification failed.
```
**含义**：服务器的主机密钥与本地 `known_hosts` 文件中记录的不一致。
**原因**：
- 服务器重装了系统
- 中间人攻击（较少见）
- 之前连接过同名 IP 的不同机器

---

## 2. 服务器端“拒绝”的配置方式

如果你是想了解**如何配置 SSH 服务器来拒绝某些连接**，常见方式：

| 配置项 | 位置 | 作用 |
|--------|------|------|
| `DenyUsers user1` | `/etc/ssh/sshd_config` | 拒绝指定用户 |
| `DenyGroups group1` | `/etc/ssh/sshd_config` | 拒绝指定组 |
| `AllowUsers user1` | `/etc/ssh/sshd_config` | 只允许指定用户 |
| `PasswordAuthentication no` | `/etc/ssh/sshd_config` | 禁止密码登录 |
| `Port 2222` | `/etc/ssh/sshd_config` | 更改默认端口，非 22 |
| 防火墙规则 | `iptables` / `firewalld` | 拒绝来自特定 IP 的连接 |

修改配置后需执行：
```bash
sudo systemctl restart sshd
```
