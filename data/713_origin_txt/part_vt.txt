### 第二步：如果日志显示“DNS 解析失败”或 fake-ip 返回了奇怪的东西

这是 TUN + fake-ip 最常见的问题——某些客户端不兼容 fake-ip 返回的虚假 IP。

**解决办法：把 Claude 的域名加入 fake-ip-filter，让它走真实 DNS**

1.  打开 Clash Verge -> **Settings**（设置）
2.  找到 **DNS** 部分，点击右侧的 **Edit**（编辑）或直接打开配置文件
3.  找到 `fake-ip-filter` 这一项
4.  添加以下内容（确保 Claude 相关的域名不走 fake-ip）：
```yaml
fake-ip-filter:
  - '+.claude.ai'
  - '+.anthropic.com'
  - '+.console.anthropic.com'
  # 如果你还知道其他 Claude 用的域名，一起加上
```
5.  保存配置，重启 Clash Verge
6.  再跑 Claude Code CLI 试试

---

### 第三步：如果日志显示“blocked”或者“Reject”

这说明你的规则把 Claude 给拦了。可能是规则配置太严格，或者你用的订阅规则误杀了 Claude。

**解决办法：手动添加 Claude 直连规则（临时验证）**

1.  打开 Clash Verge -> **Profiles**（配置）
2.  找到你当前用的配置文件，点击右侧的 **Edit**（编辑，一般是铅笔图标）
3.  找到 `rules:` 部分
4.  在**最上面**插入以下规则（优先级高，先匹配）：
```yaml
rules:
  - DOMAIN-SUFFIX,claude.ai,DIRECT
  - DOMAIN-SUFFIX,anthropic.com,DIRECT
  - DOMAIN-KEYWORD,anthropic,DIRECT
  # 然后把原来的规则放在下面
```
5.  保存，Clash Verge 会自动重载配置
6.  测试 Claude Code CLI

如果这样能上，说明是规则问题。你可以：
- 保持这个规则（就是 Claude 直连，不代理）
- 或者检查你的订阅规则哪里误杀了，联系订阅提供者修复

---
