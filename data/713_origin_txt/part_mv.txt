### 💻 方式二：通过 API 调用（开发者适用）

如果你是开发者，想在自己的应用或脚本中精确控制推理强度，可以通过 API 设置 `reasoning` 参数。

#### **核心参数**
根据官方文档，GPT-5.4 模型 (`gpt-5.4`) 支持以下五个推理强度级别[citation:2][citation:4]：

| 参数值 | 行为描述 | 适用场景 |
| :--- | :--- | :--- |
| `none` | 无链式思考，最快、最便宜 | 简单的文本转换、信息提取、格式化任务 |
| `low` | 最小程度的推理，快速检查 | 简单的问答、分类、摘要 |
| `medium` | **平衡的推理强度（默认）** | 常规的代码编写、分析，适合大部分生产环境 |
| `high` | 扩展的推理链，更全面深入 | 复杂调试、架构决策、多步骤逻辑推理 |
| `xhigh` | **最高级别的推理深度**，最慢，也最准确 | 高难度数学、大型代码重构、安全审计、前沿研究[citation:2] |

#### **代码示例 (Python)**
以下是一个调用 GPT-5.4 API 并将推理强度设置为 `xhigh` 的示例：

```python
from openai import OpenAI

client = OpenAI()

response = client.chat.completions.create(
    model="gpt-5.4",  # 指定使用 GPT-5.4 模型
    reasoning={"effort": "xhigh"},  # <--- 这里设置为你想要的强度
    messages=[
        {"role": "system", "content": "你是一名资深的 Python 架构师，负责代码审查和优化。"},
        {"role": "user", "content": "请审查下面这段代码，找出所有潜在的性能瓶颈和并发安全问题，并给出重构建议。"}
    ]
)

print(response.choices[0].message.content)
```

#### **注意事项**
- **费用更高**：`xhigh` 意味着模型内部会生成更多用于思考的 token，这些都会被计入账单。一个 `xhigh` 请求的成本可能是 `low` 请求的 **3 到 5 倍**[citation:2]。
- **并非总是更好**：**不要将 `xhigh` 作为默认选项**[citation:5]。对于一些简单的问题，过度的推理会导致“过度思考”，生成复杂、啰嗦甚至错误的答案。社区测试表明，在某些任务上，`high` 模式的表现反而优于 `xhigh`[citation:5]。

### ⚠️ 重要提醒：xHigh 不是万能药

在使用 xHigh 前，请务必理解以下几点，这能帮你避免花冤枉钱：

1.  **它是最后的手段**：官方建议，只有在你的评估明确表明能带来收益时，才使用 xhigh。它最适合那些**长时间运行、高度自主（Agent）、且对错误零容忍**的任务[citation:5]。
2.  **先优化你的提问**：在调高推理档位之前，**更应该优先优化提示词（Prompt）**[citation:5]。清晰的任务指令、明确的输出格式和边界限制，带来的提升远比盲目使用 xhigh 要显著得多[citation:6]。
3.  **提防“过度修复”**：尤其是在编程任务中，使用 xhigh 可能会导致模型“修复”比要求多得多的内容，重写整个模块而不是只改几行代码[citation:6]。因此，在请求中明确加上负面约束会很有帮助，例如：“**只修改 `auth` 函数，不要改动项目结构和其它任何文件**”[citation:6]。

### 🆓 方式一：Google AI Studio（免费试用，无需配置）

这是**最快速、零成本**的上手方式，适合想先体验模型能力的用户。

**操作步骤**：
1. 访问 [aistudio.google.com](https://aistudio.google.com/)
2. 使用 Google 账户登录
3. 在模型下拉菜单中选择 **`gemini-3.1-pro-preview`**[citation:1]
4. 直接开始输入提示词，支持上传图片、PDF 等文件进行多模态测试[citation:4]

**适用场景**：快速测试、Prompt 工程、功能探索  
**费用**：免费版有速率限制，但足以满足日常试用需求[citation:1]


### 💻 方式二：Gemini API（开发者首选）

适合有编程基础、需要将模型集成到应用或工作流中的用户。

**1. 获取 API Key**
- 访问 [makersuite.google.com/app/apikey](https://makersuite.google.com/app/apikey)
- 点击“Get API key”生成密钥
- 设置环境变量：`export GEMINI_API_KEY="你的密钥"`[citation:4]

**2. Python 调用示例**
```python
from google import genai
from google.genai import types

client = genai.Client()

response = client.models.generate_content(
    model="gemini-3.1-pro-preview",
    contents="解释量子纠缠的概念，用通俗易懂的方式",
    config=types.GenerateContentConfig(
        thinking_level="high"  # 可选: low / high
    )
)

print(response.text)
```
[citation:1][citation:4]

**3. cURL 调用示例**
```bash
curl "https://generativelanguage.googleapis.com/v1beta/models/gemini-3.1-pro-preview:generateContent" \
  -H "x-goog-api-key: $GEMINI_API_KEY" \
  -H "Content-Type: application/json" \
  -X POST \
  -d '{
    "contents": [{
      "parts": [{"text": "你的提示词"}]
    }],
    "generationConfig": {
      "thinking_level": "high"
    }
  }'
```
[citation:4]

### 🖥️ 方式三：Gemini CLI（命令行工具）

适合习惯终端操作、或需要与代码编辑器协同的开发场景。

**操作步骤**：
1. 升级到最新版：`npm update -g @google/gemini-cli`（确保版本 ≥ 0.21.1）[citation:9]
2. 运行 `/model` 命令查看可用的模型
3. 选择 **Auto (Gemini 3)** 自动路由，或使用 `-m` 参数指定：
   ```bash
   gemini -m gemini-3.1-pro-preview "你的任务"
   ```

**注意事项**：
- 使用 Gemini 3 Pro 有每日限额，超出后可降级到 2.5 Pro 或升级订阅[citation:9]
- 如果系统繁忙，CLI 会自动使用指数退避重试[citation:9]


### 🏢 方式四：企业级集成（Vertex AI / Gemini Enterprise）

适合需要生产环境部署、合规性要求高的企业用户。

**可用平台**：
- **Google Cloud Vertex AI**：完整的 MLOps 平台，支持 VPC-SC、CMEK、审计日志等企业功能[citation:1][citation:10]
- **Gemini Enterprise**：通过 Gemini for Google Workspace 的企业计划访问[citation:10]

**启用方式**：
- 在 Google Cloud Console 中启用 Vertex AI API
- 选择 `gemini-3-pro-preview` 端点
- 配置 IAM 权限后即可调用[citation:1]


### 📱 方式五：消费级产品（Gemini App / NotebookLM）

适合普通用户通过官方产品体验模型能力。

**可用产品**：
- **Gemini 应用**：网页版和移动端 App，订阅 **Google AI Pro 或 Ultra** 计划后可使用[citation:1][citation:8]
- **NotebookLM**：仅向 AI Pro 和 Ultra 订阅用户开放[citation:8]

**费用**：需要订阅 Google One AI 高级计划（Pro/Ultra）

### 💡 核心参数配置建议

Gemini 3.1 Pro 引入了 `thinking_level` 参数来控制推理深度[citation:1][citation:4][citation:7]：

| 设置 | 适用场景 |
|------|----------|
| `low` / `minimal` | 高吞吐量任务、简单问答 |
| `medium` | 日常复杂任务（推荐默认） |
| `high` | 深度研究、复杂逻辑推理、代码架构设计 |

**关于推理强度映射**：如果你习惯 OpenAI 的 `reasoning_effort` 参数，LiteLLM 已实现自动映射，可以直接使用 `"reasoning_effort": "medium"`[citation:7]。

- 知识截止：2025年1月，支持 Google Search 实时联网[citation:1]
