\section{Technical Feasibility Assessment}

\subsection{Ethical Ledger Requirements}

The framework demands infrastructure, not instant solutions. Required components:

\textbf{Currently feasible:}
\begin{itemize}
    \item \textbf{Training data provenance:} Cryptographic hashing, dataset documentation, preprocessing logs \citep{gebru2021datasheets}
    \item \textbf{Reward model versioning:} Standard software version control systems
    \item \textbf{Alignment procedure documentation:} Organizational process documentation (already required for other industries)
    \item \textbf{Reproducibility logs:} Recording hyperparameters, random seeds, major training decisions
\end{itemize}

\textbf{Early-stage but tractable:}
\begin{itemize}
    \item \textbf{Embedding geometry audits:} Characterizing semantic capability boundaries through systematic probing
    \item \textbf{Boundary verification testing:} Adversarial pressure-testing of alignment constraints
    \item \textbf{Stability analysis:} Assessing alignment robustness under distribution shift
\end{itemize}

\textbf{Open research problems:}
\begin{itemize}
    \item \textbf{Complete mechanistic interpretability:} Understanding every component of large models \citep{olah2020zoom}
    \item \textbf{Guaranteed alignment verification:} Proving systems cannot be made to produce harmful outputs
    \item \textbf{Perfect semantic boundary mapping:} Exhaustively characterizing all reachable outputs
\end{itemize}

\textbf{Honest assessment:} The ethical ledger framework is technically ambitious. It requires companies invest in infrastructure beyond current minimal practices. However, it does not require solving open research problems---it requires systematizing practices some leading labs already employ informally \citep{anthropic2023constitutional, openai2024gpt4}.

\subsection{Technical Appendix Preview}

The Appendix outlines how usage-based semantics might be operationalized for governance through: (1) Reachability analysis: Systematic probing to map capability boundaries; (2) Alignment as geometric constraint: Viewing alignment as probability density reduction in semantic subregions; (3) Auditing as boundary verification: Adversarial testing of alignment constraint robustness.

\textbf{Critical limitation:} This represents a research program, not completed technology. The Appendix proposes conceptual bridges between philosophical framework and machine learning practice---it does not claim these bridges are already constructed. Value lies in establishing clear research targets, not pretending solutions exist.

\section{Game-Theoretic Dynamics}

\subsection{Stakeholder Incentives}

\textbf{AI Companies:}

\emph{Want:}
\begin{itemize}
    \item Operational freedom to iterate on designs
    \item Predictable regulatory standards
    \item Protection from arbitrary disclosure demands
    \item Ability to maintain trade secrets
\end{itemize}

\emph{Fear:}
\begin{itemize}
    \item Government inspectors demanding daily architecture access
    \item Competitors obtaining proprietary information through discovery
    \item User lawsuits forcing unlimited disclosure
    \item Regulatory uncertainty preventing long-term planning
\end{itemize}

\emph{Framework provides:}
\begin{itemize}
    \item Fuzzy space protection (conditional on ethical ledger maintenance)
    \item Clear veil-piercing criteria (predictable standards)
    \item Oversight board buffer (no routine government architecture access)
    \item Judicial review requirement (no unilateral agency disclosure demands)
\end{itemize}

\textbf{Government Regulators:}

\emph{Want:}
\begin{itemize}
    \item Harm prevention and response capabilities
    \item Public legitimacy (demonstrable oversight)
    \item Innovation preservation (not killing beneficial AI)
    \item Tools that don't require deep technical expertise
\end{itemize}

\emph{Framework provides:}
\begin{itemize}
    \item Veil-piercing backstop (harm response tool)
    \item Oversight board (visible regulatory presence)
    \item Fuzzy space (preserves innovation incentives)
    \item Ethical ledgers (accessible documentation, not raw code)
\end{itemize}

\textbf{Users:}

\emph{Want:}
\begin{itemize}
    \item AI system benefits (access to capabilities)
    \item Protection from manipulation
    \item Autonomy preservation (freedom to use AI as desired)
    \item Accountability when harmed
\end{itemize}

\emph{Framework provides:}
\begin{itemize}
    \item Continued access (no blanket restrictions)
    \item Veil-piercing triggers (accountability for manipulation)
    \item Autonomy preservation (companies not monitoring everything)
    \item Litigation pathway (standing to sue when veil-piercing criteria satisfied)
\end{itemize}

\subsection{Stakeholder Incentive Analysis}

\textbf{Disclaimer:} The following presents intuitions about stakeholder incentives, not formal game-theoretic proof. Full equilibrium analysis with asymmetric information models remains future work (see \S7.6).

\textbf{Status quo (no framework):}
\begin{itemize}
    \item Companies: Face regulatory uncertainty, arbitrary disclosure risks
    \item Government: Lacks tools to respond to harms, faces public pressure
    \item Users: Have neither protection nor clear accountability mechanisms
    \item Result: All parties worse off than under framework
\end{itemize}

\textbf{Framework adoption:}
\begin{itemize}
    \item Companies: Accept ethical ledger burden to gain fuzzy space protection
    \item Government: Accept fuzzy space to gain oversight board + veil-piercing backstop
    \item Users: Accept some company opacity to maintain AI access + gain accountability tools
    \item Result: Each party better off than status quo, given others' acceptance
\end{itemize}

\textbf{International competition effects:}

This analysis assumes single-jurisdiction framework. In reality:
\begin{itemize}
    \item Companies might jurisdiction-shop (locate in countries with minimal oversight)
    \item Countries might race-to-bottom (weaken standards to attract AI investment)
    \item Coordination failures undermine effectiveness
\end{itemize}

These challenges require international cooperation mechanisms discussed in \S7.6. The framework's viability depends on sufficient jurisdictions adopting compatible standards---not global unanimity (which is unattainable) but critical mass among major AI-developing nations.

\section{Existing Practice and Friction Points}

\subsection{Emerging Industry Practices}

Some AI companies already implement practices resembling ethical ledger components:

\textbf{User control mechanisms:}
\begin{itemize}
    \item Memory deletion (users can remove interaction histories)
    \item Training data removal requests (where technically feasible)
    \item Custom instructions (user-specified behavioral constraints)
    \item Conversation export (users can review full interaction logs)
\end{itemize}

\textbf{Internal governance:}
\begin{itemize}
    \item Ethics review boards (varying levels of authority)
    \item Alignment testing before deployment
    \item Red-teaming exercises \citep{perez2022red}
    \item Incident response procedures
\end{itemize}

\textbf{Limitations of current practice:}
\begin{itemize}
    \item Inconsistent across companies (no industry standards)
    \item Often voluntary, not legally required
    \item Variable documentation quality
    \item Unclear what happens during ethics review
    \item No external verification mechanisms
\end{itemize}

\textbf{Framework contribution:} Systematize these emerging practices into legally enforceable baseline, while preserving space for innovation beyond minimum standards.

\subsection{Known Adversarial Dynamics}

Any governance framework must address several adversarial scenarios:

\textbf{User-side attacks:}
\begin{itemize}
    \item \textbf{Jailbreaking:} Users deliberately circumventing alignment constraints through prompt engineering \citep{wei2024jailbroken}
    \item \textbf{Prompt injection:} Embedding instructions within ostensible content \citep{greshake2023prompt}
    \item \textbf{Social engineering:} Manipulating systems through apparent legitimate use
\end{itemize}

\textbf{External attacks:}
\begin{itemize}
    \item \textbf{Model poisoning:} Adversarial data insertion during training \citep{carlini2017evaluating}
    \item \textbf{Adversarial examples:} Inputs crafted to produce specific undesired outputs \citep{goodfellow2014explaining}
    \item \textbf{API abuse:} Systematic probing to extract model information
\end{itemize}

\textbf{Company-side risks:}
\begin{itemize}
    \item \textbf{Performative compliance:} Maintaining ethical ledgers without substantive constraint
    \item \textbf{Minimal documentation:} Recording only what legally required
    \item \textbf{Ex post rationalization:} Creating alignment justifications after design decisions
\end{itemize}

\textbf{Honest limitation:} No framework eliminates all adversarial behavior. Goal is creating accountability mechanisms that catch systematic patterns, not preventing every individual failure.

\subsection{Three-Way Relationship Mapping}

Real-world governance involves complex trilateral dynamics:

\textbf{Company $\leftrightarrow$ User (Contractual):}
\begin{itemize}
    \item Terms of Service define mutual obligations
    \item Users responsible for autonomous choices within system capabilities
    \item Companies liable when design undermines autonomy (Trigger 1)
    \item Neither party can unilaterally invoke government oversight
\end{itemize}

\textbf{Government $\leftrightarrow$ Company (Regulatory):}
\begin{itemize}
    \item Trade secret protection default rule
    \item Oversight board can inspect ethical ledgers
    \item Veil-piercing enables judicial architecture access
    \item Companies not required to monitor users absent specific evidence
\end{itemize}

\textbf{User $\leftrightarrow$ Government (Citizenship/Legality):}
\begin{itemize}
    \item Users bear criminal liability for clearly illegal actions (uploading state secrets)
    \item Government cannot compel companies to surveil generally
    \item Users cannot weaponize government power to obtain architecture disclosure without showing veil-piercing criteria
\end{itemize}

\textbf{Key insight:} Each bilateral relationship has distinct legal character (contract, regulation, citizenship). Framework must respect these distinctions rather than collapsing everything into single relationship type.

\subsection{Power Asymmetries and Global Justice}

The framework as presented reflects Western legal assumptions and may reinforce existing power imbalances. This section addresses critical equity concerns that must be resolved for the framework to serve global justice.

\subsubsection{Global South Exclusion}

The framework assumes legal systems with:
\begin{itemize}
    \item Independent judiciary capable of piercing corporate veils
    \item Established trade secret protections
    \item Functioning oversight agencies insulated from capture
\end{itemize}

\textbf{Many Global South jurisdictions lack these institutional prerequisites.} Where courts are politically constrained or regulatory agencies under-resourced, the framework's three-tier structure may not function as designed.

Moreover, the framework emerges from Western corporate law traditions. Wholesale transplantation risks repeating colonial patterns of legal imperialism \citep{anghie2004imperialism}. As \citet{mutua2001savages} argues regarding human rights discourse, Western legal frameworks often impose culturally-specific values under guise of universalism. AI governance must avoid this trap.

\subsubsection{Corporate Power Disparities}

Large AI companies (OpenAI, Google, Anthropic, Meta) can afford:
\begin{itemize}
    \item Sophisticated ethical ledger infrastructure
    \item Large compliance teams
    \item Expensive litigation defending against veil-piercing claims
\end{itemize}

Smaller companies and open-source projects cannot. This creates multiple risks:

\textbf{1. Regulatory Capture:} Oversight boards may be effectively controlled by large companies with resources to shape standards. Historical precedent: financial regulation post-2008 often reflected large bank preferences \citep{johnson2010bankers}. Pattern likely repeats in AI governance.

\textbf{2. Competitive Disadvantage:} Ethical ledger requirements may function as barriers to entry, consolidating power among established players. This contradicts open innovation arguments often used to resist AI regulation \citep{mokander2021ethics}.

\subsubsection{User Agency and Marginalized Voices}

Current framing treats users as passive recipients of AI services. But users are heterogeneous, with vastly different:

\textbf{Technical literacy:} Some can jailbreak models; others cannot understand basic AI concepts. Framework assumes users can distinguish manipulation from genuine service---but marginalized users may lack digital literacy to recognize algorithmic steering.

\textbf{Access to legal resources:} Privileged users can bring veil-piercing claims; marginalized communities cannot afford litigation. Class actions may help but require legal sophistication and resources to initiate.

\textbf{Vulnerability to AI harms:} Surveillance disproportionately affects minorities \citep{benjamin2019race}. Disabled users face accessibility barriers \citep{whittaker2019ainow}. LGBTQ+ communities harmed by gender-binary systems \citep{keyes2018misgendering}. Immigrants targeted by predictive policing \citep{brayne2017big}.

\textbf{Critical problem:} Framework's veil-piercing triggers focus on aggregate harms but may miss distributional impacts. A system might pass ``autonomy-control conflation'' test for majority users while severely manipulating vulnerable subgroups.

\subsubsection{Environmental Justice}

Framework is silent on environmental impacts of:
\begin{itemize}
    \item \textbf{Compute-intensive training:} GPT-3 training generated $\sim$500 tons CO$_2$ equivalent \citep{patterson2021carbon}. Frontier models likely higher.
    \item \textbf{Ethical ledger infrastructure:} Additional compute for auditing, testing, verification
    \item \textbf{Semiconductor supply chains:} Mining rare earth elements, water usage in chip manufacturing, labor conditions in fabrication facilities
\end{itemize}

\textbf{Environmental racism:} Tech infrastructure often located near marginalized communities bearing pollution burdens without receiving economic benefits \citep{pellow2002silicon}.

\textbf{Honest limitation:} These ``mitigations'' are inadequate. The framework requires fundamental rethinking for non-Western contexts, not just minor adjustments. Future work must center Global South legal scholars, practitioners, and communities in governance design---not transplant Western models with superficial modifications.

\subsubsection{Conclusion: Framework as Partial Intervention}

We acknowledge this section does not fully resolve these profound challenges. Power asymmetries, global inequities, and environmental crises cannot be eliminated through governance design alone---they require broader political and economic transformation.

\textbf{What this framework can do:}
\begin{enumerate}
    \item Create institutional spaces where power can be contested (oversight boards, litigation)
    \item Make visible what is currently hidden (ethical ledgers documenting corporate practices, disaggregated impact assessments)
    \item Enable accountability mechanisms that previously didn't exist (veil-piercing for performative compliance, community standing for collective harms)
\end{enumerate}

\textbf{What this framework cannot do:}
\begin{enumerate}
    \item Eliminate structural inequities rooted in global capitalism
    \item Resolve fundamental conflicts between innovation and justice
    \item Replace democratic politics with technical governance solutions
\end{enumerate}

These are modest interventions in face of structural inequities. We welcome critical engagement on how the framework could better serve global justice---recognizing that perfect justice through governance design is impossible. Progress requires both better institutions and social movements transforming power relations governance alone cannot address.

\section{Conclusion and Methodology}

\subsection{Framework Summary}

This paper proposes constitutional structure for AI governance:

\textbf{Core mechanism:} ``Deliberate fuzzy space'' (conditional trade secret protection) exchanged for ethical ledger maintenance, enforced through three-tier accountability (company obligations, oversight board, judicial veil-piercing).

\textbf{Veil-piercing triggers:} Three criteria mapping to existing legal frameworks (autonomy-control conflation, profit-driven manipulation, performative alignment), enabling case law development.

\textbf{Philosophical foundation:} Usage-based semantics enabling focus on observable capabilities rather than inaccessible consciousness, operationalized through embedding space geometry (Appendix).

\textbf{Design principle:} Negotiate among stakeholders with material stakes rather than impose theorist-preferred solutions. Privilege what works in practice over what satisfies in theory.

\subsection{What This Framework Provides}

\textbf{It provides:}
\begin{itemize}
    \item Negotiation structure enabling government-industry cooperation
    \item Clear allocation of default rights and exception conditions
    \item Institutional architecture balancing innovation, oversight, and accountability
    \item Pathway for developing detailed standards through practice
    \item Complement to existing risk-based frameworks (EU AI Act, NIST RMF)
\end{itemize}

\textbf{It does NOT provide:}
\begin{itemize}
    \item Complete statutory language ready for legislative adoption
    \item Resolution of deep philosophical questions about AI consciousness
    \item Technical solutions to open alignment research problems
    \item Guarantee against all possible harms or adversarial attacks
    \item Universal solution applicable across all legal and cultural contexts
\end{itemize}

\textbf{Appropriate comparison:} Constitutional frameworks establish structural principles; statutory law provides details; regulatory guidance specifies implementation; case law develops through application. This paper operates at constitutional level---deliberately leaving specification space for stakeholders with functional knowledge.

\subsection{Methodological Reflection: Emergence from Practice}

This framework did not originate from pure theoretical derivation. It emerged from observing regulatory practice, industry behavior, and stakeholder conflicts during participation in government AI transparency assessments conducted between 2022--2024.

\textbf{Observed dynamics:}

\textbf{Government perspective:}
\begin{itemize}
    \item Policymakers expressed frustration with technical opacity: ``Engineers tell us AI is too complex to explain, then ask us to trust their safety claims''
    \item Concerns centered on control and legibility rather than specific harms
    \item Fear that AI companies are ``playing us for fools'' while building systems with unpredictable consequences
\end{itemize}

\textbf{Industry perspective:}
\begin{itemize}
    \item Companies emphasized competitive sensitivity of architectures: ``Disclosure would hand our innovations to competitors''
    \item Resistance to ``arbitrary'' disclosure demands lacking clear standards
    \item Willingness to provide process documentation if this satisfied oversight
\end{itemize}

\textbf{The pattern I observed:} Each party has legitimate concerns unaddressable through existing frameworks. Transparency mandates devastate companies without giving government usable information. Industry self-regulation lacks credibility with users. Consciousness-based approaches generate philosophical debates while harms accumulate.

\textbf{The insight:} What if governance provided conditional opacity---companies get protection from routine disclosure but lose it when behaving badly? This preserves innovation incentives while creating accountability backstop. The veil-piercing analogy emerged from recognizing this mirrors corporate governance's basic structure.

\subsection{The Zhu Suli Parallel: Practice-Grounded Jurisprudence}

Legal scholar Zhu Suli faced analogous situation in 1990s China:

\textbf{The inherited debate:}
\begin{itemize}
    \item Western-trained legal scholars: Should China adopt civil law codes or common law precedent?
    \item ``Socialist law'' practitioners: Use Ma Xiwu field adjudication (deciding disputes in farmers' fields, not courtrooms)
    \item Legal academy consensus: Ma Xiwu methods violate procedural propriety and rule of law
\end{itemize}

\textbf{Zhu Suli's intervention:}

Stop asking ``What is justice in the abstract?'' (Fregean referentialism applied to legal philosophy). Ask instead: ``In China's actual conditions, what produces outcomes relevant parties accept?'' (pragmatist usage-based approach).

His answer: Social sentiment (社会情感) + government support + jurists' constructive work = effective governance

This reframing bypassed Western categories entirely and examined actual customary practices (乡土习惯法) to discover which natural law values were already embedded in Chinese social life. Result: intellectual legitimation for ``中国特色社会主义法治体系'' (socialist rule of law with Chinese characteristics)---shifting from 法制 (legal system imposed from above) to 法治 (rule of law emerging from practice).

\textbf{This paper's analogous move:}

Just as Zhu Suli substituted ``what produces accepted outcomes?'' for ``what is justice?'', this paper substitutes ``what are verifiable capabilities?'' for ``does AI have consciousness?''

\textbf{Critical qualifications:}

\textbf{1. This is speculative analogy, not proven parallel:} Zhu Suli has not written about AI governance. We're applying his methodology, not claiming he endorsed this application.

\textbf{2. Cultural contexts differ profoundly:}
\begin{itemize}
    \item \textbf{Chinese context:} State-industry boundaries blurred; Party integrated into corporate governance; emphasis on stability over individual rights
    \item \textbf{Western context:} Separation of state and private sector; adversarial regulation; rights-based frameworks
    \item \textbf{Our framework:} Assumes independent judiciary and trade secret protections characteristic of Western legal systems
\end{itemize}

\textbf{What transfers vs.\ what doesn't:}

\emph{Transfers:}
\begin{itemize}
    \item Methodological insight: Effective governance emerges from stakeholder practice, not theorist imposition
    \item Anti-formalism: Don't force new phenomena into old categories (21st-century AI into 19th-century legal personality)
    \item Practice-observation: Study what actually happens before designing institutions
\end{itemize}

\emph{Doesn't transfer:}
\begin{itemize}
    \item Specific institutions: Chinese Party-state governance structures inapplicable to Western contexts
    \item Cultural values: Family-centered morality differs from Western individualism
    \item Political context: Authoritarian vs.\ democratic governance fundamentally different
\end{itemize}

\subsection{Why Constitutional Design Stops Here}

This paper operates at constitutional design level, not statutory specification. This reflects methodological principle, not evasion.

\textbf{Historical precedent:} Corporate law did not emerge from first principles. It crystallized from centuries of merchant practices and guild customs, commercial necessity driving institutional innovation, gradual codification of what proved workable, and government policy discretion within functional constraints.

\textbf{AI governance challenge:} We lack centuries of accumulated practice. However, we need not start from blank slate---analogous institutional solutions exist. The framework borrows corporate veil-piercing structure while acknowledging that details must emerge through industry practice, regulatory guidance, and case law development.

\textbf{The jurist's proper role:} Provide structural frameworks enabling this development, not dictate specifics that only experience can determine.

This is not false humility. It reflects epistemic realism: I cannot know which governance details will prove workable once implemented at scale. Neither can philosophers, engineers, or current policymakers. The framework creates negotiation space for parties who will operate under it to discover what works.

\subsection{Limitations and Honest Uncertainty}

\textbf{What this framework does not resolve:}

\textbf{Philosophical:} Whether AI possesses consciousness, moral status, or deserves rights. Framework brackets these questions as ungovernable, not answers them.

\textbf{Technical:} How to guarantee alignment, prevent all adversarial attacks, or achieve complete mechanistic interpretability. Recent complexity barrier proofs \citep{dalrymple2025alignment} establish fundamental intractability---framework acknowledges this rather than promising impossible verification.

\textbf{Political:} International coordination mechanisms, preventing regulatory arbitrage, resolving jurisdictional conflicts. Framework focuses on domestic governance structure. Cross-border cooperation requires separate treaty negotiations beyond this paper's scope.

\textbf{Legal:} Precise evidentiary standards, burden of proof allocation, appellate review standards. Framework identifies trigger categories but leaves specification to case law development through actual litigation.

\textbf{Game-theoretic:} Formal proof of stable equilibrium under framework vs.\ status quo. Section 5 offers institutional design intuition based on observed stakeholder incentives, not proven equilibrium characterization.

These are not embarrassing gaps---they are appropriate scope limitations. A paper cannot simultaneously operate at constitutional, statutory, regulatory, technical, and cultural levels. This one chooses constitutional architecture, leaving other levels to appropriate parties.

This appendix outlines how the philosophical framework in \S2 might connect to machine learning practice. It proposes a research program, not completed technology.

\subsection{Three Research Components}

\subsubsection{Reachability Analysis}

\textbf{Goal:} Map the complete capability surface of a deployed system---what outputs can it actually be induced to produce?

\textbf{Current technical basis:}
\begin{itemize}
    \item Mechanistic interpretability \citep{olah2020zoom} reverse-engineers model components
    \item Behavioral probing \citep{hewitt2019probes} uses classifiers to decode information in representations
    \item Dataset cartography \citep{swayamdipta2020cartography} characterizes training data geometry
\end{itemize}

\textbf{Proposed method:} Systematic adversarial audit framework that probes embedding and activation spaces to answer: ``Given current weights and known prompting techniques, what is the complete set of semantic outputs this system can generate?''

\textbf{Honest limitations:}
\begin{itemize}
    \item Exhaustive enumeration is computationally intractable for large models. Prompt space is infinite; even restricting to ``realistic'' prompts, systematic enumeration impossible.
    \item ``Complete'' capability surface is idealization---practical audits sample strategically based on threat models
    \item Current methods provide local understanding (specific circuits, features), not global guarantees about all possible behaviors
\end{itemize}

\subsubsection{Alignment as Geometric Constraint}

\textbf{Perspective:} Standard alignment techniques (RLHF, RLAIF, constitutional AI) don't ``delete'' capabilities---they make certain semantic regions statistically harder to reach by reshaping probability distributions \citep{ouyang2022training, bai2022training}.

\textbf{Geometric interpretation:}
\begin{itemize}
    \item Pre-alignment: Model has high-probability paths to harmful outputs
    \item Post-alignment: Probability density in harmful regions reduced (but not zero)
    \item Robust alignment: Low-density zones stable under distribution shift and adversarial pressure
\end{itemize}

\subsubsection{Boundary Verification}
