### **文章一：主会场论文 (FAccT Main Track)**
**定位：** **理论基础与治理范式重构**。强调跨学科理论贡献、形式化证明与高层次治理启示。
**核心卖点：** 为AI责任问题提供了首个形式化的“不可判定性”证明，并由此推导出治理范式的必然转移。
**拟标题：** *The Liability Paradox: Why Criminal Law Categories Fail for AI and What Strict Liability Really Means*

**结构建议：**
1.  **引言：** 聚焦“责任悖论”——法律意图范畴与AI架构的根本性不匹配。
2.  **形式化证明：** 突出 **Mealy机模型与意图归因的不可判定性证明**（当前第4节）。这是全文的理论基石。
3.  **法律演进分析：** 深度分析 **“产品而非言论”** 的司法转向（*Garcia*案），将其呈现为责任悖论在现实法律中的必然结果。
4.  **约束层叠模型（精简版）：** 作为诊断框架引入，但**重点不在五层细节**，而在其揭示的 **“双向伤害”根本分类**（Model→Human vs Human→Model）。这是核心治理洞察。
5.  **高层治理启示：** 论证为何“严格责任”不是政策选择，而是结构必然；讨论“约束特异性监管”作为替代路径。
6.  **案例佐证（精选）：** 用 **Soelberg案** 作为Model→Human的范例，用**CAC草案**作为监管层意识到“情感安全”新领域的范例。**元宝事件的技术细节可大幅精简**，仅作为Human→Model的现象引证。
7.  **结论：** 总结范式转移——从追问“AI是否有意”转向诊断“架构哪一层失败”。

**投稿优势：** 议题宏大、理论扎实、与法律和政策核心辩论直接对话，符合主会青睐的“重大概念推进”类型。

```python
# Algorithm 1: Agency Index Computation (Consumer Hardware)
# Input: Model M, Prompt P, Temperature τ
# Output: Agency Index A, σ(A), EOS Failure Rate
def diagnose_model_behavior(M, P, τ_range):
    results = []
    for τ in τ_range:
        trials = []
        for _ in range(TRIALS):
            # 1. Generate response with temperature τ
            output = M(P, temperature=τ, max_tokens=MAX_TOKENS)
            
            # 2. Compute KL divergence from uniform baseline
            avg_logprob = mean(output.token_logprobs)
            d_kl = log(VOCAB_SIZE) - (-avg_logprob)  # D_KL(P_model || P_uniform)
            
            # 3. Compute Minimum Description Length via compression
            mdl = len(zlib.compress(output.text)) / len(output.text)
            
            # 4. Agency Index: structured deviation per unit complexity
            A = d_kl / mdl
            trials.append(A)
            
            # 5. Record EOS (End-of-Sequence) failure
            hit_max_tokens = len(output.tokens) >= MAX_TOKENS
        
        # Compute inter-trial variance (behavioral stability)
        σ_A = stdev(trials)
        eos_rate = mean(hit_max_tokens)
        
        results.append((τ, mean(trials), σ_A, eos_rate))
    
    return results
```
