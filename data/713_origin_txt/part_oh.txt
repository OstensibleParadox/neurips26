## 计划：特征值引擎的维度耦合

### 上下文

`computeEigenstructure(estate)` 目前基于每个维度的均匀方差构建一个 7×7 的对角协方差矩阵。对对角矩阵进行特征分解得到的结果就是方差的排序——特征值就是对角线条目，特征向量是标准基向量。没有揭示任何跨维度的结构。

为了让单个产权体的特征结构变得非平凡，我们需要引入非对角线的协方差条目，用以编码教义性的维度耦合。本次 PR 向产权体数据添加一个可选的 `dimensionCouplings` schema，并修改引擎以使用该数据，同时强制执行 PSD（半正定）保证。

**范围**：仅限引擎 + schema + 数据 + 测试。不涉及可视化工作。

---

### 已采纳的审计修正

1. **PSD 有效性**：成对相关性在 `[-1, 1]` 范围内**不能保证**协方差矩阵有效。对称性是自动满足的，但半正定性不是。
2. **PSD 投影必须重构**：仅截断特征值是不够的。必须重构 `Sigma⁺ = Q * diag(max(λ_k, 0)) * Q^T`。如果必须保留对角线方差，则投影还必须恢复对角线。
3. **先验证，而非先构建再修复**：在返回之前检查 PSD。如果应用了投影，通过返回值中的一个警告标志来暴露这一事实。
4. **禁止重复对**：通过 schema 验证禁止重复的无序维度对，而不是添加一个模式字段。
5. **分数校准**：默认使用网格 `{-0.9, -0.75, -0.5, -0.25, 0, 0.25, 0.5, 0.75, 0.9}`。允许 `±1.0` 用于真正的定义恒等（会造成秩亏，但对特征分解无害）。验证使用闭区间 `[-1, 1]`。
6. **现有测试中的秩亏**：3 个产权体 → 秩为 2 的样本协方差 → 第三个分量是空的。测试必须承认这一点。
7. **缺失测试脚本**：`package.json` 中没有 `"test"` 脚本。需要添加一个。

### 步骤 3：Schema 设计 — dimensionCouplings

向产权体对象添加可选字段：

```json
"dimensionCouplings": [
  {
    "dimensions": ["alienation", "inheritability"],
    "correlation": 0.9,
    "doctrine": "De Donis Conditionalibus 1285 — alienation blocked and inheritability entailed simultaneously"
  }
]
```

**验证规则**（在引擎中强制执行，而非仅靠约定）：
- `dimensions` 必须是一个包含两个有效 `DIMENSIONS` 字符串的数组
- `correlation` 必须在 `[-1, 1]` 内（闭区间）。`±1.0` 会造成秩亏（奇异性），但由于我们从不求逆协方差矩阵，这对特征分解无害
- 禁止重复的无序对（如果 `[A,B]` 和 `[B,A]` 同时出现则拒绝）
- `doctrine` 字符串为必填（非空）

**校准规则**（供数据编写者参考）：

| 幅度 | 含义 |
|------|------|
| 1.0 | 定义恒等：完美的共同决定。造成秩降——两个维度在其范围内携带冗余信息。仅在教义使两个维度形式上不可分时使用 |
| 0.9 | 接近定义性的共同变动；一个维度几乎蕴含另一个 |
| 0.75 | 强烈的教义关联；存在常见的例外 |
| 0.5 | 中等的结构性关联；重要但非构成性 |
| 0.25 | 微弱但真实的倾向 |
| 0 | 没有稳定的成对结构关系 |

**符号约定**：相关性的符号编码的是**协变方向**，而非绝对水平对比。问题是：“在这个产权体的不确定性带内，如果维度 A 向其上限波动，维度 B 是倾向于向其上限（+）还是下限（-）波动？”这是一个条件倾向性问题，可由教义专家判断回答。

**示例**：fee tail 的 alienation `[0,10]` 和 inheritability `[70,90]` 处于相反的绝对水平，但符号是 `-0.9`，因为放松 alienation 约束（向 10 移动）会破坏支持严格 lineal inheritance 的限定结构（将 inheritability 推向 70）。协变是反向的。

**零方差维度**：引用范围 `[a, a]`（sigma = 0）的维度的耦合在 schema 上是有效的——即使在数值上惰性，它们也记录了教义结构。协方差条目 `C[i][j] = rho * 0 * sigma_j = 0` 是自然的，因此在构建时不需要特殊处理。这些耦合在计算结果中被标记为**休眠（dormant）**。

### 步骤 4：引擎修改 — eigenEngine.js

#### 4a：添加 `validateCouplings(couplings)`（私有）

- 检查每个条目：有效维度、相关性在 `[-1, 1]` 内（闭区间）、doctrine 非空
- 检测重复的无序对 → 抛出 `RangeError`
- 返回验证后的数组（如果输入是 `undefined` 或 `null`，则返回空数组）

#### 4b：添加 `buildCovarianceMatrix(estate)`（私有）

1. 基于每个维度的均匀方差构建对角矩阵（当前行为）
2. 如果存在 `dimensionCouplings`，调用 `validateCouplings`
3. 对每个耦合 `{dimensions: [A, B], correlation: rho}`：
   - `sigma_i = sqrt(uniformVariance(estate.ranges[A]))`
   - `sigma_j = sqrt(uniformVariance(estate.ranges[B]))`
   - `C[i][j] = C[j][i] = rho * sigma_i * sigma_j`
4. 返回 Matrix 对象

#### 4c：添加 `ensurePSD(covarianceMatrix)`（私有）

对零方差维度使用**分区嵌入**方法，然后在活跃子矩阵上执行**单次相关空间投影**（不是朴素的特征值截断——参见 Higham 2002）。

1. 提取 `sigmas = sqrt(diagonal of covariance)`
2. 将维度划分为**活跃集 A** = `{i : sigma_i > 1e-12}` 和**冻结集 F** = 补集
3. 对完整协方差矩阵进行特征分解
4. 检查是否有任何特征值 `< -epsilon`（`epsilon = 1e-10` 用于数值噪声）
5. 如果所有特征值 `>= -epsilon`：返回 `{matrix, eigenpairs, projected: false, frozenDimensions: F}`
6. 如果有任何特征值 `< -epsilon`：
   a. 提取 `|A| × |A|` 的活跃子矩阵 `C_A`
   b. 转换为相关矩阵：`R[i][j] = C_A[i][j] / (sigma_i * sigma_j)` — 所有 sigma 为正，无除零
   c. 对 R 进行特征分解
   d. 将负特征值截断为 0
   e. 重构 `R⁺ = Q * diag(max(λ_k, 0)) * Q^T`
   f. 重新归一化：`R⁺[i][j] /= sqrt(R⁺[i][i] * R⁺[j][j])` — 强制对角线为 1.0
   g. 转换回活跃协方差：`C_A⁺[i][j] = R⁺[i][j] * sigma_i * sigma_j`
   h. 将 `C_A⁺` 重新嵌入到完整的 7×7 矩阵中（冻结的行/列保持为零）
   i. 对恢复后的完整协方差矩阵重新进行特征分解
   j. 返回 `{matrix: C⁺, eigenpairs: new, projected: true, frozenDimensions: F}`

#### 4d：修改 `computeEigenstructure(estate)`

```
assertEstate(estate)
covarianceMatrix = buildCovarianceMatrix(estate)
{matrix, eigenpairs, projected} = ensurePSD(covarianceMatrix)
// eigenpairs 已在 ensurePSD 内部通过 sortEigenpairs 排序

return {
  eigenvalues: [...],
  eigenvectors: [...],
  principalAxes: [...],
  projected,           // 新增：布尔值 — 是否应用了 PSD 投影
  hasCouplings,        // 新增：布尔值 — 产权体是否有 dimensionCouplings
  frozenDimensions,    // 新增：string[] — 方差为零的维度（数值上惰性）
}
```

**向后兼容性**：没有 `dimensionCouplings` 的产权体产生与今天完全相同的结果。`projected` 为 `false`，`hasCouplings` 为 `false`。

#### 4e：更新注释

替换第 145–146 行的现有注释：
```

// is the diagonal covariance of seven independent uniform marginals.
```
改为根据是否存在耦合进行分支的逻辑。
