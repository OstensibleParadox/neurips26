
## 二、基本语法
```bash
pandoc 输入文件 -o 输出文件
```

## 三、常见格式转换

### 1. Markdown 转其他格式
```bash
# Markdown → Word
pandoc input.md -o output.docx

# Markdown → PDF（需要 LaTeX）
pandoc input.md -o output.pdf

# Markdown → HTML
pandoc input.md -o output.html

# Markdown → 带样式的 HTML
pandoc input.md -s -o output.html

# Markdown → 幻灯片（reveal.js）
pandoc input.md -t revealjs -s -o slides.html
```

### 2. 其他格式转 Markdown
```bash
# Word → Markdown
pandoc input.docx -o output.md

# HTML → Markdown
pandoc input.html -o output.md

# LaTeX → Markdown
pandoc input.tex -o output.md
```

## 四、常用选项

### 1. 元数据管理
```bash
# 使用 YAML 元数据块
pandoc input.md --metadata title="我的文档" -o output.pdf

# 指定模板
pandoc input.md --template template.tex -o output.pdf
```

### 2. 引用和参考文献
```bash
# 使用 BibTeX 参考文献
pandoc input.md --bibliography refs.bib --citeproc -o output.docx

# 使用 CSL 格式
pandoc input.md --bibliography refs.bib --csl chicago.csl --citeproc -o output.pdf
```

### 3. 表格处理
```bash
# 包含原始表格
pandoc input.md -s --self-contained -o output.html
```

## 五、实用示例

### 示例 1：完整的学术文档转换
```bash
pandoc paper.md \
  --bibliography references.bib \
  --csl apa.csl \
  --filter pandoc-crossref \
  -o paper.pdf
```

### 示例 2：批量处理
```bash
# 转换目录下所有 Markdown 文件
for file in *.md; do
    pandoc "$file" -o "${file%.md}.pdf"
done
```

### 示例 3：自定义模板
```bash
# 生成默认模板
pandoc -D latex > template.tex

# 使用自定义模板
pandoc input.md --template mytemplate.tex -o output.pdf
```

## 六、扩展功能

### 1. 使用过滤器
```bash
# 数学公式编号
pandoc math.md --filter pandoc-crossref -o output.pdf

# 图表自动编号
pandoc doc.md --number-sections -o output.pdf
```

### 2. 支持的文件格式
- **输入格式**：markdown, html, latex, docx, epub, etc.
- **输出格式**：pdf, html, docx, epub, latex, pptx, etc.

## 七、小技巧

1. **查看支持格式**：
```bash
pandoc --list-input-formats
pandoc --list-output-formats
```

2. **从网页获取内容**：
```bash
curl -s "https://example.com" | pandoc -f html -t markdown -o page.md
```

3. **批量转换图片引用**：
```bash
pandoc -f html -t markdown --wrap=none input.html
```

4. **保持软换行**：
```bash
pandoc input.md --wrap=preserve -o output.txt
```

## 八、常见问题

1. **中文支持**：
```bash
# 编译中文 PDF
pandoc input.md -o output.pdf --pdf-engine=xelatex -V mainfont="SimSun"
```

2. **目录生成**：
```bash
pandoc input.md --toc -o output.html
```

3. **语法高亮**：
```bash
pandoc code.md --highlight-style pygments -o output.html
```

Pandoc 的灵活性很高，可以通过组合不同的选项实现复杂的文档处理需求。建议使用 `pandoc --help` 查看所有可用选项。

## Pandoc 名字的由来

**Pandoc** 是 **"Pan-Document Converter"**（全文档转换器）的缩写和组合词：

- **Pan-**（希腊语前缀）：意思是"全部"、"所有"、"万能"
- **Doc**：Document（文档）的缩写

所以字面意思是 **"万能文档转换器"**

## 英语中的发音

- 通常发音为 **/ˈpændɒk/** 或 **/pænˈdɒk/**
- 有点像 "pan"（平底锅） + "dock"（码头）连读
- 作者 John MacFarlane 本人确认发音为 **"pan-dock"**（重音在第一音节）

## 有趣的背景

这个名字的选择反映了 Pandoc 的核心功能：
1. **Pan-** 体现了它的**通用性**（支持 40+ 种文档格式）
2. **-doc** 表明了它的**文档处理**本质
3. 名字简洁易记，有技术工具的感觉

ssh 的用法
**SSH（Secure Shell）** 是一种加密的网络协议，用于安全地访问和管理远程计算机。以下是 SSH 的主要用法和常见命令：

---

### **1. 基本连接**
```bash
ssh user@hostname
```
- `user`：远程主机的用户名  
- `hostname`：远程主机的 IP 地址或域名  
示例：  
```bash
ssh john@192.168.1.10
ssh admin@example.com
```

---

### **2. 指定端口**
如果远程 SSH 服务不在默认端口 22：
```bash
ssh -p port user@hostname
```
示例：  
```bash
ssh -p 2222 user@example.com
```

---

### **3. 使用密钥登录（无密码）**
- **生成密钥对**（本地）：
  ```bash
  ssh-keygen -t rsa -b 4096
  ```
- **将公钥上传到远程主机**：
  ```bash
  ssh-copy-id user@hostname
  ```
- **连接时自动使用私钥**：
  ```bash
  ssh -i ~/.ssh/id_rsa user@hostname
  ```

---

### **4. 执行远程命令**
```bash
ssh user@hostname "command"
```
示例：  
```bash
ssh user@example.com "ls -la /tmp"
```

---

### **5. 端口转发**
- **本地转发**（将远程端口映射到本地）：
  ```bash
  ssh -L local_port:remote_host:remote_port user@hostname
  ```
  示例：访问远程数据库（通过跳板机）：
  ```bash
  ssh -L 3306:db_server:3306 user@jump_host
  ```

- **远程转发**（将本地端口映射到远程）：
  ```bash
  ssh -R remote_port:localhost:local_port user@hostname
  ```

---

### **6. 文件传输**
- **SCP 复制文件**：
  ```bash
  scp file.txt user@hostname:/path/to/dest  # 上传
  scp user@hostname:/path/to/file.txt ./    # 下载
  ```

- **SFTP 交互式传输**：
  ```bash
  sftp user@hostname
  ```

---

### **7. 连接配置简化**
在 `~/.ssh/config` 中预设连接参数：
```
Host myserver
    HostName example.com
    User john
    Port 2222
    IdentityFile ~/.ssh/id_rsa
```
之后只需：
```bash
ssh myserver
```

---

### **8. 调试与日志**
```bash
ssh -v user@hostname      # 显示详细信息
ssh -vvv user@hostname    # 最高调试级别
```

---

### **9. 保持连接活跃**
在 `~/.ssh/config` 中添加：
```
Host *
    ServerAliveInterval 60
    ServerAliveCountMax 3
```

---

### **常见问题解决**
1. **权限错误**：确保 `~/.ssh` 目录权限为 `700`，私钥为 `600`。
2. **连接被拒绝**：检查远程主机的 SSH 服务状态（`sudo systemctl status sshd`）。
3. **密钥认证失败**：确认公钥已添加到远程 `~/.ssh/authorized_keys` 中。

---

### **安全建议**
- 禁用密码登录，仅使用密钥认证。
- 更改默认 SSH 端口（需修改 `/etc/ssh/sshd_config`）。
- 使用 `fail2ban` 防止暴力破解。

---

通过以上命令和配置，你可以高效、安全地使用 SSH 管理远程服务器。

sudo apt和sudo apt-get的区别
`sudo apt` 和 `sudo apt-get` 都是 Debian/Ubuntu 系统中的包管理工具，它们之间既有联系也有区别。以下是主要差异：

---

## **1. 历史背景**
- **`apt-get`**：较老的命令行工具，功能稳定但用户友好性较差（早期版本无进度条等）。
- **`apt`**：2014 年引入的**高级包装工具（APT）的新前端**，旨在合并 `apt-get`、`apt-cache` 等工具的功能，提供更友好的交互体验。

---

## **2. 主要区别**

| 特性 | `sudo apt` | `sudo apt-get` |
|------|-----------|---------------|
| **进度条** | 有（彩色进度条） | 无（仅文本输出） |
| **命令简化** | 常用命令更短（如 `apt install`） | 命令较长（如 `apt-get install`） |
| **推荐操作** | 提示可升级的包数量、自动删除无用包建议 | 无此类提示 |
| **子命令整合** | 整合了 `apt-get`、`apt-cache` 的部分功能（如 `apt search`） | 需要分别使用 `apt-get` 和 `apt-cache` |
| **向后兼容** | 不完全兼容所有 `apt-get` 参数 | 参数和行为保持稳定 |
| **脚本使用建议** | **不建议在脚本中使用**（输出格式可能变化） | **推荐用于脚本**（稳定解析） |

---

## **3. 常用命令对比**

| 功能 | `apt` 命令 | `apt-get` 等价命令 |
|------|-----------|-------------------|
| 安装包 | `apt install <包名>` | `apt-get install <包名>` |
| 删除包 | `apt remove <包名>` | `apt-get remove <包名>` |
| 更新源列表 | `apt update` | `apt-get update` |
| 升级所有包 | `apt upgrade` | `apt-get upgrade` |
| 搜索包 | `apt search <关键词>` | `apt-cache search <关键词>` |
| 显示包信息 | `apt show <包名>` | `apt-cache show <包名>` |
| 清理无用包 | `apt autoremove` | `apt-get autoremove` |
| 完全升级 | `apt full-upgrade` | `apt-get dist-upgrade` |

---

## **4. 使用建议**
- **日常交互使用**：推荐 `apt`（更友好、有进度提示）
- **脚本或自动化**：推荐 `apt-get`（行为稳定、输出可靠）
- **兼容性**：两者底层使用相同的包管理系统（`dpkg` 和 APT 库），安装结果一致

---

## **5. 示例对比**
```bash
# 安装 htop（apt 显示进度条和颜色）
sudo apt install htop

# 同等功能的 apt-get 命令
sudo apt-get install htop
```

---

## **总结**
`apt` 是改进版的前端工具，适合**人工交互**；  
`apt-get` 是经典工具，适合**脚本和需要稳定输出的场景**。  
两者在功能上大部分重叠，可根据需求选择。

这两个命令在英语中的命名和含义如下：

## **1. `apt`**
- **全称**：**Advanced Package Tool**（高级包装工具）
- **发音**：/eɪ piː tiː/（按字母读 A-P-T），也有人读作 /æpt/（类似单词“apt”）
- **含义**：
  - 在英语中，“apt”本身是一个形容词，意为“恰当的、合适的”
  - 但这里主要是**缩写**，指代整个包管理系统

## **2. `apt-get`**
- **解析**：`apt` + `-get`
  - `apt` = Advanced Package Tool
  - `get` = 获取（动词）
- **字面意思**：“从高级包工具中获取”
