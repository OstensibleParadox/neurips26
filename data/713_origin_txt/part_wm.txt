- persistent API credential storage and usage

## 8.3 The Inverse Theorem

The relationship between scaffolding, governance, and risk can be expressed formally.

Let:

- **C** = capability introduced by scaffolding
- **G** = governance mechanisms controlling that capability
- **R** = system risk

Then:

- If **G ≥ C**, scaffolding improves safety (capability is governed)
- If **G < C**, scaffolding amplifies risk (capability exceeds governance)

The MedBench result demonstrates the first condition: sufficient governance (verification steps, constrained tool use) applied to capability (agent reasoning) produces safety gains.

The OpenClaw exposure demonstrates the second condition: capability without governance produces systemic vulnerability.

This produces a structural paradox:

- **one of the most dangerous ways** to deploy models without governance, due to capability amplification

## 8.6 Implication for Agent System Design

The combined evidence from MedBench and the OpenClaw incident yields a clear design principle:

**Agent capability must be matched by proportional governance mechanisms.**

Required controls include:

- **capability-based permission systems** that limit what each agent can access
- **runtime policy verification** that checks actions before execution
- **network isolation** preventing exposed control planes
- **action auditing** providing detectability of compromise
- **constrained tool execution** with least-privilege design

Without such controls, agent scaffolding transforms model errors—or deliberate model compromise—into system-level failures with operational consequences far beyond those of traditional language model deployment.

# 8. The Scaffolding Duality: Capability Gains and Risk Amplification

## 8.1 Empirical Evidence for Scaffolding as a Safety Mechanism

Recent investigations into agentic systems have demonstrated that architectural scaffolding can substantially improve model safety and reliability. The MedBench evaluation platform, developed by the Shanghai Artificial Intelligence Laboratory, provides controlled experimental evidence of this phenomenon. In their comparative study, the introduction of structured agent pipelines increased safety performance metrics from 18.4% to 88.9%—an improvement of 70.5 percentage points attributable solely to architectural intervention rather than underlying model enhancement (Shanghai AI Laboratory, 2026).

The operational mechanism proceeds as follows:

```
model output → structured reasoning → verification → constrained execution → outcome
```

This pipeline introduces three critical governance functions. First, **structured reasoning** imposes logical coherence on model outputs before they inform action selection. Second, **verification steps** evaluate proposed actions against safety constraints prior to execution. Third, **constrained tool invocation** limits the operational scope of executed actions to predefined boundaries. Collectively, these mechanisms constitute a form of **inference-time governance** that compensates for the model's inherent limitations in self-monitoring and risk assessment.

## 8.2 The Structural Expansion of Attack Surface

Bare language models exhibit a fundamentally limited failure surface. The interaction architecture reduces to:

```
prompt → model → text output
```

Under this paradigm, the maximum credible adverse outcome is the generation of misinformation or incorrect content. The model observes but does not act; its influence terminates at the boundary of textual generation.

Agentic systems fundamentally reconfigure this architecture:

```
prompt → reasoning → tool execution → external effects
```

This reconfiguration introduces a qualitative shift in system behavior. Failures no longer terminate at the model's textual output but propagate through execution channels into external systems. The agent acquires **operational capability**: the ability to read files, transmit messages, invoke application programming interfaces, and modify persistent system state. Each capability introduced by scaffolding constitutes a novel propagation channel through which compromise can extend.
