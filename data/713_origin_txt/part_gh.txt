functools是啥
**functools** 是 Python 的标准库模块，提供了一系列用于高阶函数（操作其他函数的函数）的工具，常用于函数式编程。主要功能包括：

## 核心功能：

### 1. **@functools.wraps**
装饰器，用于保留被装饰函数的元数据
```python
from functools import wraps

def my_decorator(func):
    @wraps(func)  # 保留原函数的名称、文档等
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper
```

### 2. **functools.partial**
冻结部分参数，创建新函数
```python
from functools import partial

def power(base, exp):
    return base ** exp

square = partial(power, exp=2)  # 固定指数为2
cube = partial(power, exp=3)    # 固定指数为3

print(square(5))  # 25
print(cube(3))    # 27
```

### 3. **functools.lru_cache**
最近最少使用缓存装饰器
```python
from functools import lru_cache

@lru_cache(maxsize=128)
def fibonacci(n):
    if n < 2:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

# 自动缓存计算结果，避免重复计算
```

### 4. **functools.reduce**
对可迭代对象累积应用函数
```python
from functools import reduce

nums = [1, 2, 3, 4, 5]
product = reduce(lambda x, y: x * y, nums)  # 1*2*3*4*5 = 120
```

### 5. **functools.cmp_to_key**
将比较函数转换为key函数
```python
from functools import cmp_to_key

def compare(a, b):
    return a[1] - b[1]  # 按元组第二个元素排序

items = [('a', 3), ('b', 1), ('c', 2)]
sorted_items = sorted(items, key=cmp_to_key(compare))
```

### 6. **functools.total_ordering**
自动生成缺失的比较方法
```python
from functools import total_ordering

@total_ordering
class Student:
    def __init__(self, name, grade):
        self.name = name
        self.grade = grade
    
    def __eq__(self, other):
        return self.grade == other.grade
    
    def __lt__(self, other):
        return self.grade < other.grade
    
# 自动生成 __le__, __gt__, __ge__ 等方法
```

## 实用场景：

1. **性能优化**：`lru_cache`用于缓存昂贵函数调用
2. **代码复用**：`partial`用于创建专用函数
3. **装饰器开发**：`wraps`保持函数元数据
4. **函数组合**：`reduce`处理数据流
5. **面向对象**：`total_ordering`简化比较操作

functools 让函数式编程在 Python 中更加方便，特别是在需要函数柯里化、记忆化缓存或高阶函数操作的场景中非常有用。

将旧 iPad 数据迁移到新 iPad 有以下几种方法，推荐按顺序尝试：

### **方法一：快速开始（最快最方便，推荐首选）**
**条件**：两台 iPad 均运行 **iOS 12.4 / iPadOS 13** 或更高版本，且蓝牙已开启。
**步骤**：
1. 将两台 iPad **靠近放置**，新 iPad 开机并解锁旧 iPad。
2. 新 iPad 上会出现【快速开始】弹窗，点击【继续】。
3. 用旧 iPad 扫描新 iPad 上的**动画图案**。
4. 在新 iPad 上输入旧 iPad 的**锁屏密码**。
5. 选择【从 iPad 传输】，然后按照提示完成迁移。

**注意**：
- 确保两台 iPad 电量充足或连接电源。
- 传输时间取决于数据大小，请耐心等待。

---

### **方法二：iCloud 备份与恢复**
**条件**：旧 iPad 已备份到 iCloud，且新 iPad 能稳定连接 Wi-Fi。
**步骤**：
1. **备份旧 iPad**：
   - 连接 Wi-Fi，进入【设置】→ 点击顶部头像 → 【iCloud】→ 【iCloud 备份】。
   - 点击【立即备份】，等待完成。
2. **恢复新 iPad**：
   - 新 iPad 开机，在“你好”界面按提示操作，直到进入【App 与数据】界面。
   - 选择【从 iCloud 备份恢复】→ 登录 Apple ID → 选择**最新的备份**。
   - 等待恢复完成（时间取决于备份大小和网速）。

---

### **方法三：电脑备份与恢复（Mac/PC）**
**条件**：需要有电脑（Mac 或安装了 iTunes/Finder 的 PC）。
**步骤**：
1. **备份旧 iPad 到电脑**：
   - 用数据线连接旧 iPad 与电脑。
   - **Mac（macOS Catalina 或更高）**：打开 Finder，在边栏选择 iPad → 点击【立即备份】。
   - **PC 或 macOS Mojave 及更早**：打开 iTunes → 点击设备图标 → 选择【立即备份】。
2. **恢复备份到新 iPad**：
   - 连接新 iPad 到同一台电脑。
   - 在 Finder/iTunes 中选择新 iPad → 点击【恢复备份】→ 选择旧 iPad 的备份文件。

---

### **方法四：直接迁移（有线连接）**
