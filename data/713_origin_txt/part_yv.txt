## 🚀 最快的方案：配置镜像源 + 直接拉取

### 第一步：配置镜像源（一劳永逸）

**Windows**：
1. 打开环境变量设置（右键"此电脑"→属性→高级系统设置→环境变量）
2. 在"用户变量"里点"新建"，填入：
   - 变量名：`OLLAMA_MODEL_SERVER`
   - 变量值：`https://mirror.ollama.com`
3. 一路点确定保存，**重启一下终端**（PowerShell 或 CMD）[citation:1]

**Linux/macOS**（如果你用的是这些系统）：
```bash
echo 'export OLLAMA_MODEL_SERVER="https://mirror.ollama.com"' >> ~/.bashrc
source ~/.bashrc
```

> 这个 `mirror.ollama.com` 是国内可用的镜像地址，能显著提升下载速度[citation:1][citation:8]。如果这个不行，可以试试 `https://cnb.cool/hex/ollama`[citation:8]。


### 第二步：直接拉取你想要的模型

**选一个流量友好的版本先试试**（约 1GB）：

```bash
ollama pull hf.co/mradermacher/Llama-3.2-1B-Instruct-abliterated3-i1-GGUF:Q4_K_M
```

**如果你想要 8B 版本的**（约 4.4GB，比默认的 Q8 省一半流量）：

```bash
ollama pull hf.co/mradermacher/Meta-Llama-3-8B-Instruct-abliterated-i1-GGUF:Q4_K_M
```

> 用 `hf.co/用户名/模型名:量化版本` 这种格式，Ollama 会直接从 Hugging Face 拉取 GGUF 文件，走你刚配置的镜像加速[citation:1][citation:6]。


## 📦 备用方案：镜像源不生效的话

如果上面的命令还是慢，用这个**手动下载 + 导入**的方法，完全不依赖网络稳定性：

1. **去国内镜像站下载 GGUF 文件**  
   打开 [hf-mirror.com](https://hf-mirror.com)，搜索 `mradermacher/Llama-3.2-1B-Instruct-abliterated3-i1-GGUF`，找到 `Q4_K_M.gguf` 文件下载（~1GB）。

2. **导入 Ollama**  
   在 GGUF 文件所在目录，创建一个 `Modelfile` 文件，内容就一行：
   ```dockerfile
   FROM ./你下载的文件名.gguf
   ```
   然后执行：
   ```bash
   ollama create my-llama -f ./Modelfile
   ```

3. **运行**  
   ```bash
   ollama run my-llama
   ```
