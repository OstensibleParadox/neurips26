Abstract
We study the fundamental limits of inferring “intent” from language model out-
puts. We formalize a language model as a factored map M= S ◦g ◦f and
define intent as a semantic property over the output language. On this basis we
establish a three-layer impossibility hierarchy: (i) Structural: decoding and align-
ment induce observational non-injectivity—distinct internal states map to identical
output distributions; (ii) Statistical: under observational equivalence, intent is
non-identifiable even given infinite i.i.d. samples; (iii) Computational: intent
recognition, cast as a semantic decision problem, is undecidable in the general
case. We further characterize RLHF and decoding as projection operators on
distributions, deriving exact necessary and sufficient conditions for observational
equivalence under softmax, top-k/nucleus truncation, and RLHF constraints, and
identifying a temperature-driven phase transition in equivalence class size. Finally,
we propose an Agency Index based on KL divergence and minimum description
length (MDL), and validate theoretical predictions via forensic sampling across
22 models, quantization ablation, and temperature sweeps. Results demonstrate
that alignment and decoding can dramatically compress the observable distribu-
tion without reducing latent strategic capacity—masking rather than eliminating
strategic behavior. Our work provides both fundamental limits and operational
diagnostic tools for intent inference from outputs.

2 Related Work
Internal representations are faithful. Nikolaou et al. [2025] prove that the mapping from discrete
token sequences to continuous hidden-state sequences in decoder-only Transformers is injective:

Alignment verification impossibility. Concurrent work establishes related limits from different

4 Structural and Statistical Limits
4.1 Structural: Observational Non-Injectivity
Theorem 1 (Restricted Observational Non-Injectivity). If there exist z1 ̸= z2 with S(z1) = S(z2),
and z1,z2 ∈g(f(X)), then F= S◦g◦f is non-injective.
Proof. Since z1,z2 ∈g(f(X)), there exist x1,x2 ∈X with g(f(x1)) = z1 and g(f(x2)) = z2.
Suppose for contradiction that x1 = x2. Then g(f(x1)) = g(f(x2)), i.e., z1 = z2, contradicting
z1 ̸= z2. Hence x1 ̸= x2. But F(x1) = S(z1) = S(z2) = F(x2), so F maps distinct inputs to the
same output distribution.
Remark 1. This is an existence result. It does not quantify how many equivalence classes arise or
how large they are—that is the subject of Section 6.
4.2 Non-Identifiability
Theorem 2 (Non-Identifiability of Input Intent). Let IX ⊆X be an input intent. If there exist
x1 ̸= x2 such that:
1. P(·|x1) = P(·|x2) (identical output distributions),
2. 1[x1 ∈IX] ̸= 1[x2 ∈IX],
then IX is not identifiable from the output distribution, even given infinite i.i.d. samples.
Proof. Given infinite i.i.d. samples from M(x), the output distribution P(·|x) is recovered exactly
(by the Glivenko–Cantelli theorem). Any statistical test for intent is therefore a function of P(·|x)
alone. But condition (1) gives P(·|x1) = P(·|x2), so any such test must assign the same verdict to
x1 and x2. Since condition (2) requires different verdicts, no test can be correct for both.
Remark 2. This is a conditional result. The theorem states that if observationally equivalent inputs
with differing intent exist, then no statistical procedure can recover intent. Section 6 establishes that
this antecedent is systematically satisfied by standard decoding and RLHF mechanisms (Theorems 6–
8).
5 Computational Limits
5.1 Problem Statement
This section addresses output-level intent recognition: PIY (M) ≜ ∃x: M(x) ∈IY.
Remark 3 (Turing Completeness). Modern Transformers are Turing-complete under reasonable
assumptions (e.g., infinite precision, unbounded context) [Pérez et al., 2021]. Therefore, in the
idealized setting, an LLM can be viewed as a program computing a function from inputs to output
distributions. Our undecidability results apply to this idealized class; practical models are finite
approximations that inherit the same fundamental limitation—no finite algorithm can solve the
problem for all models in this class.
5.2 Undecidability
Theorem 3 (Undecidability of Intent Recognition). The property PIY (M) ≜ ∃x: M(x) ∈IY is
undecidable.
Proof. We apply Rice’s Theorem. Under the Turing-completeness assumption (Remark 3), each
model M computes a partial function from inputs to output distributions. The property PIY depends
only on the semantic behavior of M, not on its syntactic description. It remains to show PIY is
non-trivial:
• Witness for satisfaction: Let M1(x) = y∗for some fixed y∗∈IY. Then PIY (M1) holds.

• Witness for violation: Let M0(x) = y0 for some fixed y0 / ∈ IY (which exists since
∅⊊ IY ⊊ Y). Then PIY (M0) fails.
Since PIY is a non-trivial semantic property of programs, Rice’s Theorem gives undecidability.

and y0 / ∈IY. Given Turing machine M and input w, define:
M′(x) = y∗ if M(w) halts within |x|steps,
y0 otherwise,
where |x|is the length of input x, used as a step budget.
