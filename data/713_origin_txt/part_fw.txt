System reboot的命令怎么写
System reboot（系统重启）的命令取决于您使用的操作系统。以下是常见系统的命令：

## **Windows**
1. **图形界面**：
   - 开始菜单 → 电源 → 重启

2. **命令行**：
   ```cmd
   shutdown /r /t 0
   ```
   - `/r` 表示重启
   - `/t 0` 表示延迟0秒（立即执行）
   - 需要管理员权限

3. **其他选项**：
   ```cmd
   shutdown /r /t 60 /c "系统将在60秒后重启"
   ```
   - `/t 60` 延迟60秒
   - `/c` 添加注释

## **Linux/Unix/macOS**
1. **最常用命令**：
   ```bash
   sudo reboot
   ```
   或
   ```bash
   sudo shutdown -r now
   ```

2. **定时重启**：
   ```bash
   sudo shutdown -r +10  # 10分钟后重启
   sudo shutdown -r 23:00  # 在23:00重启
   ```

3. **取消计划的重启**：
   ```bash
   sudo shutdown -c
   ```

## **macOS（除了上述Linux命令）**
- 图形界面：苹果菜单 → 重新启动
- 快捷键：`Control + Command + 电源按钮`

## **注意事项**
1. **保存工作**：重启前请保存所有文档和工作
2. **权限**：大多数重启命令需要管理员/root权限（使用`sudo`或管理员命令行）
3. **远程服务器**：谨慎操作，确保有恢复访问的方法

## **推荐的安全做法**
```bash
# Linux示例：先同步磁盘数据再重启
sudo sync && sudo reboot
```
