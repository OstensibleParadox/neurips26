```

## 3. 使用 `bash` 脚本

```bash
#!/bin/bash
# 保存为 flatten.sh 并赋予执行权限
while IFS= read -r -d $'\0' file; do
    # 生成唯一文件名，避免冲突
    newname=$(echo "$file" | sed 's|[/ ]|_|g')
    mv "$file" "./$newname"
done < <(find . -type f -print0)

# 删除空目录
find . -type d -empty -delete
```

## 4. 使用专门的工具

**`tree` + 自定义脚本**：
```bash
# 先安装 tree
# sudo apt install tree  # Debian/Ubuntu
# sudo yum install tree  # RHEL/CentOS

# 获取所有文件路径
tree -if --noreport | grep -v '/$' | while read file; do
    mv "$file" .
done
```

## 注意事项：

1. **文件名冲突**：如果不同目录有同名文件，会相互覆盖。建议：
   ```bash
   # 使用带路径的新文件名
   find . -type f -exec sh -c 'mv "$1" "./$(echo "$1" | tr "/" "_")"' _ {} \;
   ```

2. **安全操作**：
   ```bash
   # 先预览效果，不实际执行
   find . -type f -exec echo "mv {} ." \;
   
   # 或使用 -i 交互模式
   find . -type f -exec mv -i {} . \;
   ```

3. **删除空目录**（移动文件后）：
   ```bash
   find . -type d -empty -delete
   ```

```
