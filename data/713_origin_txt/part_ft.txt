## 📱 **每次使用软件的步骤**：

### **方法1：快速启动（推荐）**

1. **打开 Terminal**
2. **进入项目目录**：
   ```bash
   cd ~/Documents/WeFlow
   ```

3. **启动软件**：
   ```bash
   npm run electron:dev
   ```

4. **等待软件启动**（约10-30秒）

5. **使用软件** - Electron 窗口会自动打开

6. **关闭时**：在 Terminal 按 `Ctrl + C` 停止

### **方法2：创建快捷脚本**

1. **创建一个启动脚本**：
   ```bash
   # 在桌面创建启动脚本
   cd ~/Desktop
   cat > start_weflow.sh << 'EOF'
   #!/bin/bash
   echo "正在启动 WeFlow..."
   cd ~/Documents/WeFlow
   npm run electron:dev
   EOF
   
   # 给脚本执行权限
   chmod +x start_weflow.sh
   ```

2. **以后每次双击这个脚本文件**即可启动

### **方法3：使用 alias（最快的方法）**

1. **在 shell 配置中添加别名**：
   ```bash
   # 编辑 zsh 配置文件
   nano ~/.zshrc
   
   # 在文件末尾添加：
   alias weflow="cd ~/Documents/WeFlow && npm run electron:dev"
   ```

2. **重新加载配置**：
   ```bash
   source ~/.zshrc
   ```

3. **以后只需要在 Terminal 输入**：
   ```bash
   weflow
   ```
