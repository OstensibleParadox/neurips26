生成一个随机数的python

## 1. 基础随机数生成

```python
import random

# 生成0到1之间的随机浮点数
print("随机浮点数(0-1):", random.random())

# 生成指定范围内的随机整数
print("1-10之间的随机整数:", random.randint(1, 10))

# 生成指定范围内的随机浮点数
print("1-10之间的随机浮点数:", random.uniform(1, 10))

# 从列表中随机选择一个元素
fruits = ['苹果', '香蕉', '橙子', '葡萄']

# 随机打乱列表
numbers = [1, 2, 3, 4, 5]
random.shuffle(numbers)
print("打乱后的列表:", numbers)
```

## 2. 安全的随机数生成（密码学安全）

```python
import secrets

# 生成安全的随机整数
print("安全的随机整数(1-100):", secrets.randbelow(100) + 1)

# 生成随机字节
print("随机字节:", secrets.token_bytes(16))

# 生成随机十六进制字符串
print("随机十六进制:", secrets.token_hex(8))

# 生成随机URL安全的字符串

```

## 3. 带权重的随机选择

```python
import random

# 带权重的随机选择
items = ['普通', '稀有', '史诗', '传说']
weights = [70, 20, 8, 2]  # 概率总和100%

# 单个随机选择

```

## 4. 高级随机数生成

```python
import random

# 生成指定长度的随机数字序列
def generate_random_code(length=6):
    return ''.join(str(random.randint(0, 9)) for _ in range(length))

# 生成随机密码（包含数字、大小写字母）
def generate_password(length=8):
    import string
    chars = string.ascii_letters + string.digits
    return ''.join(random.choice(chars) for _ in range(length))
```

## 6. 实用示例：随机验证码生成器

```python
import random
import string

def generate_verification_code(style='mixed', length=6):
    """
    生成随机验证码
    style: 'digits'（纯数字）, 'letters'（纯字母）, 'mixed'（混合）
    """
    if style == 'digits':
        chars = string.digits
    elif style == 'letters':
        chars = string.ascii_uppercase
    else:
        chars = string.digits + string.ascii_uppercase
    
    return ''.join(random.choice(chars) for _ in range(length))

# 测试不同风格的验证码
print("纯数字验证码:", generate_verification_code('digits'))
print("纯字母验证码:", generate_verification_code('letters'))
print("混合验证码:", generate_verification_code('mixed', 8))
```

SaaS pricing page是什么
**SaaS pricing page** 直译为中文是 **“SaaS定价页面”**。

它是软件即服务（SaaS）类型公司的网站上最重要的页面之一。这个页面专门用来向潜在客户展示不同套餐的价格、功能以及订阅选项，目的是说服访客注册、购买或升级为付费用户。

以下是关于 SaaS Pricing Page 的详细解析：

### 1. 它长什么样？
通常，一个标准的 SaaS 定价页面包含以下核心元素：

-   **套餐表格：** 最常见的布局是并列几个卡片，一般分为 3-4 个档位（例如：入门版、专业版、企业版）。
-   **价格标签：** 清晰显示每月或每年的费用。
-   **功能列表：** 每个套餐下会用列表（通常是勾选标记）列出该套餐包含的核心功能、使用限制（如存储空间、项目数、团队成员数）。
-   **行动号召按钮（CTA）：** 例如“免费试用”、“立即购买”、“联系销售”。
-   **计费切换：** 通常有一个开关，让用户选择按月付费还是按年付费（按年通常会有折扣）。
-   **FAQ（常见问题解答）：** 页面下方通常会解答关于退款、合同、隐藏费用等问题。

### 2. 它的主要目标是什么？
-   **转化：** 把免费用户或者好奇的访客转化为付费客户。
-   **透明度：** 让客户清楚了解需要花多少钱，能获得什么价值。
-   **筛选客户：** 通过区分不同价位，帮助不同规模的企业找到适合自己的方案（小公司选便宜的，大公司选功能全的）。

### 3. 常见的 SaaS 定价模式
在定价页面上，你通常会看到以下几种定价策略：

-   **分层定价：** 固定几个套餐（如$9/月，$29/月，$99/月），功能依次增加。这是最常见的。
-   **按使用量付费：** 根据用户的实际用量收费（例如 API 调用次数、存储的GB数）。
