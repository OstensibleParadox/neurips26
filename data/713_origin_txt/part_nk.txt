github 设置远端同步
在 GitHub 上设置远端同步，通常是指将本地仓库与远程仓库（GitHub）关联并同步代码。以下是常见场景的操作步骤：

---

## 1. 已有本地仓库，关联到 GitHub 远端

### 第一步：在 GitHub 上创建空仓库
- 登录 GitHub，点击右上角 “+” → “New repository”
- 填写仓库名，**不要**勾选 “Initialize this repository with a README”
- 创建后复制仓库地址（HTTPS 或 SSH）

### 第二步：关联本地仓库
```bash
# 进入本地仓库目录
cd your-project

# 添加远程仓库（origin 是远程仓库的别名）
git remote add origin https://github.com/你的用户名/仓库名.git

# 确认远程仓库已添加
git remote -v
```

### 第三步：推送本地代码到远端
```bash
# 第一次推送，设置上游分支
git push -u origin main
# 或如果默认分支是 master
git push -u origin master
```

之后就可以直接用 `git push` 同步了。

---

## 2. 从 GitHub 克隆已有仓库

```bash
# 克隆到本地（会自动关联远端）
git clone https://github.com/用户名/仓库名.git

# 进入目录
cd 仓库名
```

克隆后远端已经自动配置好，可直接使用 `git pull` 和 `git push`。

---

## 3. 常用同步命令

| 操作 | 命令 |
|------|------|
| 拉取远端更新 | `git pull origin main` |
| 推送本地更新 | `git push origin main` |
| 查看远端地址 | `git remote -v` |
| 修改远端地址 | `git remote set-url origin 新地址` |
| 删除远端 | `git remote remove origin` |

---

## 4. 配置 SSH（免密推送）

如果不想每次输入用户名密码，建议使用 SSH：

1. 生成 SSH 密钥（如果还没有）：
   ```bash
   ssh-keygen -t ed25519 -C "your-email@example.com"
   ```

2. 添加公钥到 GitHub：
   - `cat ~/.ssh/id_ed25519.pub` 复制内容
   - GitHub → Settings → SSH and GPG keys → New SSH Key

3. 使用 SSH 地址关联远端：
   ```bash
   git remote set-url origin git@github.com:用户名/仓库名.git
   ```

## 完整步骤：通过 SSH 添加 origin

### 第一步：检查或生成 SSH 密钥

```bash

# 推荐使用 ed25519 算法

```

按提示操作：

- 可以设置密码短语（passphrase）或留空
