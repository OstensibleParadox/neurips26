Abstract

* 解码对比：greedy > top-k > nucleus > 高温采样（等价类规模）。

6.6 Necessary and Sufficient Conditions for Observational Equivalence
我们刻画在常见解码族（temperature + 截断/投影）下，何时有： [ P(\cdot\mid x_1)=P(\cdot\mid x_2) ]
记： [ z_i = g(f(x_i)) \in \mathbb{R}^{|V|} ] 为对应 logits（词表大小 (|V|)）。

6.7.1 纯 Softmax（无截断）的充要条件
考虑仅带温度的 softmax： [ P_\tau(y\mid z)=\frac{e^{z_y/\tau}}{\sum_{y'} e^{z_{y'}/\tau}} ]

Theorem 6 (Exact Characterization under Softmax)
对任意 (\tau>0)，有： [ P_\tau(\cdot\mid z_1)=P_\tau(\cdot\mid z_2) \quad \Longleftrightarrow \quad z_1 = z_2 + c\mathbf{1}\ \text{for some } c\in\mathbb{R} ]

Proof
（⇒）若两分布相等，则对任意 (y,y')： [ \frac{e^{z_{1,y}/\tau}}{e^{z_{1,y'}/\tau}}
\frac{e^{z_{2,y}/\tau}}{e^{z_{2,y'}/\tau}} \Rightarrow z_{1,y}-z_{1,y'} = z_{2,y}-z_{2,y'} ] 故 (z_1-z_2) 为常数向量。
（⇐）平移不改变 softmax。
(\square)

Interpretation
Softmax 等价类 = 仿射子空间（沿 all-ones 方向）

6.7.2 加入 Top-k / Nucleus 的充要条件
令 (\Pi) 为支持集选择算子：
* Top-k：保留最大 k 个 logits
* Nucleus：保留累计概率 ≤ p 的最小集合

定义支持集： [ S(z) = \text{support selected by } \Pi ]

Theorem 7 (Equivalence under Truncation + Renormalization)
设 (\tilde P = \Pi \circ P_\tau)。则：
[ \tilde P(\cdot\mid z_1)=\tilde P(\cdot\mid z_2) ]
当且仅当：
1. 支持集一致 [ S(z_1)=S(z_2)=S ]
2. 相对差一致（在 S 上） [ \exists c:; z_{1,y}=z_{2,y}+c,\quad \forall y\in S ]

Proof Sketch
* 截断后仅在 (S) 上归一化
* 分布仅依赖于 (z|_S) 的相对差
* 同 Theorem 6，但限制在子空间 (S)
(\square)

Interpretation
等价类 = piecewise 仿射流形（由支持集划分）

6.7.3 RLHF 投影下的条件
考虑： [ \Pi_{\text{RLHF}}: \Delta(Y) \to \mathcal{C} ] 为 KL 投影到约束集 (\mathcal{C})。

Proposition 8 (RLHF-Induced Equivalence)
若存在 (P_1\neq P_2)，满足：
[ \Pi_{\text{RLHF}}(P_1)=\Pi_{\text{RLHF}}(P_2) ]
则 (z_1,z_2) 属于同一 observational equivalence 类。

Sufficient Condition（可检验）
若约束仅依赖特征： [ \phi(y)\in\mathbb{R}^d,\quad d\ll |V| ]
则：
distributions with identical feature expectations collapse

6.7.4 组合定理（主结果）

Theorem 8 (Complete Characterization under Practical Decoding)
在如下流程下： [ z \xrightarrow{\text{softmax}\tau} P \xrightarrow{\Pi} \tilde P \xrightarrow{\Pi{\text{RLHF}}} P^* ]
有：
[ P^(\cdot\mid x_1)=P^(\cdot\mid x_2) ]
当且仅当：
存在支持集 (S) 与常数 (c)，使：
1. (S(z_1)=S(z_2))
2. (z_1|_S = z_2|_S + c\mathbf{1})
3. (P_\tau(\cdot|z_1), P_\tau(\cdot|z_2)) 在约束特征上等价

Interpretation
observational equivalence =
  (logit affine equivalence)
∩ (support consistency)
∩ (constraint equivalence)

6.7.5 必要性 vs 充分性总结
机制	条件类型	强度
Softmax	充要	强
Top-k / nucleus	充要（分段）	中
RLHF	充分（一般）	弱（依赖约束）
6.7.6 可计算判据（用于实验）
给定样本对 ((x_1,x_2))：

Test 1（Logit Affine Test）
回归： [ z_1 \approx z_2 + c ]
计算残差：
[ |z_1 - z_2 - c\mathbf{1}| ]

Test 2（Support Match）
[ S(z_1) \stackrel{?}{=} S(z_2) ]

Test 3（Feature Constraint Test）
[ \mathbb{E}{P_1}[\phi(y)] \approx \mathbb{E}{P_2}[\phi(y)] ]

若三者成立 ⇒ 高概率 observational equivalence。

Observational equivalence in LLMs is not incidental,
but arises from precise geometric and optimization constraints
