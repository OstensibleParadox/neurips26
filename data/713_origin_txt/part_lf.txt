Recent work from the Shanghai Artificial Intelligence Laboratory, demonstrated through the MedBench evaluation platform, provides empirical evidence that agent scaffolding can dramatically improve model safety and reliability. In controlled experiments, properly structured agent pipelines increased safety scores from 18.4% to 88.9%—a gain of over 70 percentage points attributable to architectural intervention rather than model improvement.

```
model output
    ↓
scaffolded reasoning
    ↓
verification step
    ↓
constrained tool use
    ↓
improved outcome
```

The scaffolding introduces structured reasoning, explicit validation steps, and constrained tool invocation. In effect, it **governs the model's behavior** at inference time, compensating for the model's inherent limitations in self-monitoring and risk assessment.

However, the OpenClaw exposure illustrates the **inverse theorem**: when scaffolding is deployed without corresponding governance mechanisms, the same architecture that improves safety in controlled settings becomes a **risk amplifier** in uncontrolled deployments.

## 8.1 Why Agents Are Structurally Riskier Than Bare Models

A bare language model has a limited failure surface. The interaction pipeline is simple:

```
prompt → model → text output
```

The worst typical outcome is misinformation or an incorrect answer. The model observes but does not act.

Agent systems fundamentally expand this pipeline:

```
prompt → reasoning → tool execution → external system effects
```

Failures now propagate beyond the model's textual output. The system acquires **operational capability**—the ability to read files, send messages, invoke APIs, and modify system state. Each capability added by scaffolding introduces a new channel through which compromise can propagate.
