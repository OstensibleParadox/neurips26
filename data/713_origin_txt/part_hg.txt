怎样用brew install安装缺失的字体
使用 Homebrew 安装字体有几种方法，以下是详细步骤：

## 1. 添加字体仓库
首先需要添加字体相关的仓库：
```bash
# 添加官方的字体仓库
brew tap homebrew/cask-fonts
```

## 2. 查找需要的字体
```bash
# 搜索字体（以 Fira Code 为例）
brew search font

# 搜索特定字体
brew search font- | grep fira
```

## 3. 安装字体
```bash
# 安装字体
brew install --cask font-fira-code

# 或者简化写法
brew install font-fira-code
```

## 4. 常用字体安装示例
```bash
# 编程字体
brew install font-fira-code
brew install font-jetbrains-mono
brew install font-cascadia-code
brew install font-source-code-pro

# 中文字体

brew install font-noto-sans-cjk  # Google Noto 字体

# 其他常用字体
brew install font-inter
brew install font-roboto
```

## 5. 管理已安装的字体
```bash
# 查看已安装的字体
brew list --cask | grep font

# 更新所有字体
brew upgrade --cask $(brew list --cask | grep font)

# 卸载字体
brew uninstall --cask font-fira-code
```

## 6. 查找缺失的字体
如果你知道缺失的字体的确切名称，可以通过以下方式查找：
```bash
# 模糊搜索
brew search --cask "font-*" | grep -i "字体关键词"

# 查看所有可用字体
brew search --cask font- | less
```

## 注意事项：
1. 安装后可能需要重启应用才能看到新字体
2. 有些字体可能需要手动在应用中启用
3. 确保已安装最新版 Homebrew：
   ```bash
   brew update
   ```

## 推荐的工作流：
```bash
# 1. 先查找
brew search font- | grep -i "你要找的字体名"

# 2. 安装
brew install font-查到的字体名称

# 3. 重启应用
```
