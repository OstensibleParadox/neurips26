### 查看 base 环境的大包

```bash
# 激活 base 环境
conda activate base

# 列出所有包并按大小排序
conda list | while read line; do 
    package=$(echo $line | awk '{print $1}')
    if [ -n "$package" ] && [ "$package" != "#" ]; then
        size=$(conda list --explicit | grep -E "^$package" | wc -l 2>/dev/null)
        echo "$line"
    fi
done
```

但是这样不太准确。更精确的方法是：

```bash
# 进入 base 环境的 site-packages 目录看大小
cd $(conda info --base)/lib/python*/site-packages
du -sh * | sort -hr | head -20
```

或者更直接地：

```bash
# 使用 conda 的包大小信息
conda list --explicit --md5 | while read line; do
    if [[ $line =~ ^http ]]; then
        size=$(curl -sI $line | grep -i content-length | awk '{print $2}')
        echo "$line: $size bytes"
    fi
done
```

不过这些命令可能比较复杂。最简单的方法：

```bash
# 列出所有包并显示安装大小（如果支持）
conda list --export > /tmp/conda_packages.txt
cat /tmp/conda_packages.txt
```
