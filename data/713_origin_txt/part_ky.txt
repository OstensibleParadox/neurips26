## 🎯 安全删除 auth 但不碰 skills/agents

### 方法一：精准打击（只删认证）

```bash
# 1. 先看看 Claude 的配置目录结构
ls -la ~/.config/claude/
ls -la ~/Library/Application\ Support/claude/

# 2. 通常长这样：
~/.config/claude/
  ├── auth.json          ← 只删这个！（认证信息）
  ├── config.json        ← 你的设置
  ├── skills/           ← 你的技能 (别动)
  ├── agents/           ← 你的 agent 设定 (别动)
  └── ...

# 3. 只删 auth.json
rm ~/.config/claude/auth.json

# 或者如果它在别的地方
rm ~/Library/Application\ Support/claude/auth.json 2>/dev/null
```

### 方法二：用 find 精准定位（怕你找不到）

```bash
# 找到所有 claude 相关的 auth 文件，但只删 auth
find ~/.config -path "*/claude/*auth*" -type f -delete 2>/dev/null
find ~/Library -path "*/claude/*auth*" -type f -delete 2>/dev/null

# 确认没删错（应该只剩 skills/agents）
ls -la ~/.config/claude/
```

### 方法三：安全模式（先备份再删）

```bash
# 1. 先备份整个 claude 配置
cp -r ~/.config/claude ~/.config/claude.backup.$(date +%Y%m%d)

# 2. 查看 auth 文件在哪
file $(find ~/.config ~/Library -path "*/claude/*" -name "*auth*" 2>/dev/null)

# 3. 手动删掉看到的 auth 文件
rm /path/to/specific/auth.json
```

## 🔍 验证 skills/agents 还在不在

删完后检查：

```bash
# 应该看到你的 skills 和 agents 目录还在
ls -la ~/.config/claude/skills/
ls -la ~/.config/claude/agents/

# 如果空着，可以从备份恢复
cp -r ~/.config/claude.backup.*/skills/* ~/.config/claude/skills/ 2>/dev/null
cp -r ~/.config/claude.backup.*/agents/* ~/.config/claude/agents/ 2>/dev/null
```

## 🎯 最安全的做法（强烈推荐）

```bash
# 直接用 claude auth logout（它只删认证，不动其他）
claude auth logout

# 验证一下
ls -la ~/.config/claude/  # skills/agents 应该还在
```

**`claude auth logout` 本身就是专门只删认证信息的，不会碰你的 skills 和 agents！**

| 备份后再删 | 先 cp 备份再删 | ⭐⭐⭐ 最稳妥 |

## 🔍 为什么会这样？

你用的这个 find 命令：

**问题在哪**：
- 它匹配的是 `*/claude/*auth*`
- 如果 claude 目录结构是扁平的，没有 `*/claude/xxx/auth` 这种层级
- 可能直接把 `claude` 目录本身当匹配项给删了？
