## PDFをOCRしてテキスト変換する方法

### 方法1: PDFを画像変換 → OCR（手動）

```bash
# PDFを画像に変換
brew install poppler  # 既に入っていますが念のため
pdftoppm -png 入力.pdf 出力画像プレフィックス

# TesseractでOCR（複数画像を処理）
for i in *.png; do
    tesseract "$i" "${i%.png}" -l jpn+eng  # 日本語+英語の場合
done

# 結合してテキストファイルに
cat *.txt > 出力.txt
```

### 方法2: OCRmyPDFを使用（推奨）

OCRmyPDFはPDFをOCR処理して、検索可能なPDFに変換します。

```bash
# OCRmyPDFをインストール
brew install ocrmypdf

# OCR処理（画像PDFをテキスト付きPDFに）
ocrmypdf 入力.pdf 出力.pdf -l jpn+eng

# テキスト抽出
pdftotext 出力.pdf 出力.txt
```

### 方法3: ワンライナーでテキスト抽出

```bash
# PDFを画像変換→OCR→テキスト出力
pdftoppm -png 入力.pdf temp | \
for i in temp-*.png; do
    tesseract "$i" stdout -l jpn+eng >> 出力.txt
    rm "$i"
done
```

## Markdown形式で出力したい場合

### 方法A: OCR結果を手動でMarkdown化
```bash
# テキスト抽出後、Markdown形式に整形
pandoc 出力.txt -o 出力.md
```

### 方法B: 高度なOCR+Markdownツール
```bash
# markerというツール（Pythonベース）を試す

```
