你总结的这些MATLAB优化函数非常准确！下面我对每个函数进行详细补充和解释，方便你更系统地理解：

## 1. **fminunc（光滑无约束优化）**
```matlab
% 使用示例
options = optimoptions('fminunc','GradObj','on','Hessian','on');
[x,fval] = fminunc(@rosenbrock_with_grad,x0,options);
```
**特点：**
- 基于梯度/海森矩阵（BFGS拟牛顿法）
- 适合连续可导的凸或非凸函数
- 可指定解析梯度加速收敛
- **收敛速度**：局部超线性收敛

## 2. **fminsearch（非光滑无约束）**
```matlab
% Nelder-Mead单纯形法
[x,fval] = fminsearch(@non_smooth_func,x0);
```
**特点：**
- Nelder-Mead直接搜索法（无需导数）
- 对非光滑、噪声函数稳健
- 适用于低维问题（n<20）
- **缺点**：收敛速度慢，高维效果差

## 3. **fmincon（有约束优化）**
```matlab
% 包含各种约束
[x,fval] = fmincon(@objfun,x0,A,b,Aeq,beq,lb,ub,@nonlcon);
```
**约束类型：**
- 线性不等式/等式约束
- 变量上下界
- 非线性约束
- **算法选项**：内点法、SQP、有效集法

## 4. **lsqnonlin（非线性最小二乘）**
```matlab
% 最小化残差向量范数
[x,resnorm] = lsqnonlin(@residual_func,x0,lb,ub);
```
**应用场景：**
- 参数估计
- 模型校准
- 非线性回归
- **优势**：利用最小二乘结构提高效率

## 5. **lsqcurvefit（曲线拟合专用）**
```matlab
% 数据拟合接口
[x,resnorm] = lsqcurvefit(@model_func,x0,xdata,ydata);
```
**特点：**
- lsqnonlin的封装版
- 专门用于y = f(x,θ)形式拟合
- 自动计算残差，使用更直观

## 6. **全局优化算法**
### **遗传算法 (ga)**
```matlab
options = optimoptions('ga','PopulationSize',100);
[x,fval] = ga(@objfun,nvars,A,b,Aeq,beq,lb,ub,@nonlcon);
```
### **粒子群优化 (particleswarm)**
```matlab
[x,fval] = particleswarm(@objfun,nvars,lb,ub);
```

**全局优化特点：**
- 避免陷入局部最优
- 适用于多峰、非凸问题
- **代价**：计算量大、收敛慢
- 通常与局部优化结合使用

## 📊 **选择指南**

| 问题类型 | 首选函数 | 备选方案 |
|---------|---------|---------|
| 光滑无约束 | fminunc | fmincon（无约束模式） |
| 非光滑/噪声 | fminsearch | patternsearch |
| 线性约束 | fmincon | quadprog（二次规划） |
| 非线性约束 | fmincon | - |
| 最小二乘 | lsqnonlin | lsqcurvefit（拟合用） |
| 多峰优化 | ga/particleswarm | MultiStart+fmincon |

## 💡 **实用建议**
1. **混合策略**：先用全局优化粗搜索，再用局部优化精细调整
2. **梯度提供**：尽量提供解析梯度（收敛速度显著提升）
3. **问题缩放**：确保变量量级相近（提高数值稳定性）
4. **初始点敏感**：多尝试不同初始点，特别是非凸问题

glob用法
`glob` 模块用于查找符合特定规则的文件路径名，类似于命令行中的通配符匹配。以下是最常用的用法：

## 基本用法

### 1. **查找当前目录下的文件**
```python
import glob

# 查找所有 .txt 文件
txt_files = glob.glob("*.txt")
print(txt_files)

# 查找所有 .py 文件
py_files = glob.glob("*.py")
```

### 2. **使用通配符**
```python
# * 匹配任意多个字符
files = glob.glob("data/*.csv")  # data目录下所有csv文件

# ? 匹配单个字符
files = glob.glob("image?.jpg")  # 匹配 image1.jpg, imageA.jpg 等

# [] 匹配指定字符
files = glob.glob("test[0-9].txt")  # test1.txt, test2.txt 等
files = glob.glob("test[abc].txt")  # testa.txt, testb.txt, testc.txt
```

### 3. **递归查找（Python 3.5+）**
```python
# ** 递归匹配所有子目录
all_py_files = glob.glob("**/*.py", recursive=True)

# 特定深度的递归
deep_files = glob.glob("src/**/*.py", recursive=True)
```

## 常用函数

### `glob.glob()` - 返回列表
```python
import glob

# 返回匹配的文件路径列表
files = glob.glob("data/*.csv")
for file in files:
    print(f"找到文件: {file}")

# 返回绝对路径
abs_files = glob.glob("/home/user/*.txt")
```

### `glob.iglob()` - 返回生成器（内存更友好）
```python
import glob

# 返回迭代器，适合大量文件
for file in glob.iglob("**/*.py", recursive=True):
    print(file)
    # 可以提前中断，节省资源
```

### `glob.escape()` - 转义特殊字符（Python 3.4+）
```python
import glob

# 当文件名包含通配符时
filename = "file[1].txt"
escaped = glob.escape(filename)  # 转义特殊字符
files = glob.glob(escaped)  # 正确查找
```

## 实际示例

### 示例1：批量处理文件
```python
import glob
import os

# 获取所有图片文件
image_files = glob.glob("images/*.jpg") + \
              glob.glob("images/*.png") + \
              glob.glob("images/*.gif")

for img_path in image_files:
    # 处理每个图片文件
    print(f"处理: {img_path}")
    # 获取文件名（不含路径）
    filename = os.path.basename(img_path)
    # 获取文件大小
    size = os.path.getsize(img_path)
```

### 示例2：查找特定模式的文件
```python
import glob

# 查找所有以数字结尾的日志文件
log_files = glob.glob("logs/app_*.log")

# 查找备份文件（如 file.bak, file.backup）
backup_files = glob.glob("*.*[0-9]")  # file.1, file.2 等
backup_files = glob.glob("*.bak") + glob.glob("*.backup")
```

### 示例3：组织查找模式
```python
import glob
from pathlib import Path

# 使用 pathlib 结合 glob
path = Path(".")

# 查找所有 .py 和 .txt 文件
files = list(path.glob("*.py")) + list(path.glob("*.txt"))

# 递归查找所有特定扩展名
all_csv = list(Path("data").rglob("*.csv"))
```

## 注意事项

1. **路径分隔符**：建议使用 `/`（跨平台兼容）
2. **隐藏文件**：`glob` 默认不匹配以 `.` 开头的文件
3. **排序**：`glob` 返回的结果是未排序的，需要时使用 `sorted()`
4. **性能**：大量文件时使用 `iglob()` 避免内存问题
5. **大小写敏感**：在 Windows 上不敏感，在 Unix/Linux 上敏感

## 常见模式示例
```python
# 所有文件
all_files = glob.glob("*")

# 特定扩展名
extensions = ['jpg', 'png', 'gif']
all_images = []
for ext in extensions:
    all_images.extend(glob.glob(f"*.{ext}"))

# 日期格式的文件
date_files = glob.glob("2024-*.log")  # 2024-01-01.log 等
```

`glob` 是文件操作中非常实用的模块，特别适合批量文件处理场景。
