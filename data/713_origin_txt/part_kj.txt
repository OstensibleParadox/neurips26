## 解决方案5: 使用Python脚本（自动处理编码）

创建一个 `pdf2text.py` 文件：

```python
import os
import subprocess
import sys

def convert_pdf_to_text(pdf_file, output_file):
    # 方法1: 尝试pdftotext
    try:
        subprocess.run(['pdftotext', '-layout', '-enc', 'UTF-8', pdf_file, output_file])
        print(f"已保存到: {output_file}")
    except:
        # 方法2: 如果失败，用pdfimages + tesseract
        print("使用OCR方法...")
        # 提取图片
        subprocess.run(['pdfimages', '-png', pdf_file, 'temp_img'])
        
        # OCR每张图片
        for i in range(100):  # 最多100页
            img_file = f"temp_img-{i:03d}.png"
            if not os.path.exists(img_file):
                break
            txt_file = f"temp_txt_{i:03d}.txt"
            subprocess.run(['tesseract', img_file, txt_file.replace('.txt', ''), '-l', 'chi_sim+eng'])
        
        # 合并所有txt
        with open(output_file, 'w', encoding='utf-8') as outfile:
            for i in range(100):
                txt_file = f"temp_txt_{i:03d}.txt"
                if os.path.exists(txt_file):
                    with open(txt_file, 'r', encoding='utf-8') as infile:
                        outfile.write(infile.read())
                    os.remove(txt_file)
        
        # 清理临时图片
        for i in range(100):
            img_file = f"temp_img-{i:03d}.png"
            if os.path.exists(img_file):
                os.remove(img_file)
        
        print(f"OCR完成，已保存到: {output_file}")

if __name__ == "__main__":
    if len(sys.argv) != 3:
        print("用法: python pdf2text.py 输入.pdf 输出.txt")
    else:
        convert_pdf_to_text(sys.argv[1], sys.argv[2])
```

这是一个很有意思的观察。网页版免费、API收费，看起来矛盾，其实是AI大模型公司一套精心设计的商业策略。它们就像一家餐厅，用免费试吃的样品吸引你进门，但如果你想打包带走在自己的聚会上招待客人，那就得付钱了。

简单来说，**网页版免费是为了抢占市场和收集数据，而API收费则是为了覆盖成本和实现技术变现**[citation:2][citation:5]。这个策略之所以能跑通，背后有四个关键原因：

### 🆓 vs. 💰 免费网页版与付费API的四大核心差异

| 维度 | 免费网页版 / 开源模型 | 付费API服务 |
| :--- | :--- | :--- |
| **目标用户** | **普通用户 & 开发者**：满足日常聊天、信息查询、学习等轻量级需求[citation:1][citation:6]。 | **企业与开发者**：需要将AI集成到自己的APP、产品或业务流程中，追求稳定、高效、可定制[citation:1][citation:2]。 |
| **商业逻辑** | **抢占市场与生态构建**：通过免费吸引海量用户，形成数据和流量入口，并收集反馈优化模型[citation:1][citation:6][citation:10]。同时，开源可以构建技术生态，吸引全球开发者参与，提升影响力[citation:2][citation:4]。 | **成本覆盖与价值变现**：API调用会产生实实在在的算力成本。收费可以覆盖这部分支出，并将技术价值转化为稳定收入，反哺未来的研发[citation:2][citation:5]。 |
| **成本结构** | **主要由厂商承担**。每个用户的对话都会消耗一定的推理算力，但由于是零散、低频的使用，平均成本可以被厂商的规模效应摊薄。此外，训练模型的**一次性巨额投入**（如GPT-4训练成本超7800万美元[citation:8]）也是由厂商承担，网页版是回收成本的手段之一。 | **成本与使用量强相关**。高并发、大规模的商业调用会消耗巨大的算力资源。例如，部署一个700亿参数的Llama 3.3模型，仅存储权重就需要141GB显存，需要多张昂贵的GPU协同工作[citation:7]。API收费直接与token消耗挂钩，确保了服务的成本能被覆盖[citation:2]。 |
| **提供的价值** | **基础体验 & 品牌认知**。让用户体验到模型的核心能力，培养用户习惯和对品牌的信任感。免费服务通常有**使用频率、并发数、响应速度的限制**[citation:9]。 | **专业服务 & 商业保障**。提供**稳定SLA（服务等级协议）、高并发处理能力、专属算力资源、数据隐私保护、模型微调定制**等企业级服务[citation:2][citation:5]。 |

### 💡 深度解析：为什么这个模式行得通？

1.  **成本“双低”秘籍：技术让免费成为可能**
    如今大模型免费成为趋势，首要原因是技术迭代让成本急剧下降。有专家预测，**使用AI的成本每12个月下降10倍**[citation:1]！同时，通过自研芯片（如百度昆仑芯）、优化网络和分布式训练框架，大厂的训练和推理成本已降至一年前的1%[citation:4]。这给了头部厂商打“免费牌”的底气。

2.  **生态“阳谋”：用开源构建护城河**
    当开源模型能达到闭源模型80%的性能，而成本仅为10%时，闭源的壁垒就消失了[citation:1][citation:6]。厂商索性将模型开源，吸引全球开发者在此基础上开发各类应用，这些应用的成功会反过来巩固底层开源模型的标准和生态位[citation:4]。这就像安卓系统，开源免费，但谷歌通过GMS服务和API调用获得收益。

3.  **付费API：研发的“造血机器”**
    对于企业而言，训练下一代更强大的模型（如多模态模型）需要海量资金[citation:2]。付费API正是这台“造血机器”。例如，DeepSeek将API收入定向投入到**算力储备（采购新一代GPU）、数据工程（利用付费用户脱敏数据优化模型）和顶尖人才吸引**上，形成“收入-研发-竞争力”的增强回路[citation:5]。

4.  **价值分层：满足不同需求**
