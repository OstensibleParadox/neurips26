## 🎯 安全删除 auth 但不碰 skills/agents

### 方法一：精准打击（只删认证）

```bash
# 1. 先看看 Claude 的配置目录结构
ls -la ~/.config/claude/
ls -la ~/Library/Application\ Support/claude/

# 2. 通常长这样：
~/.config/claude/
  ├── auth.json          ← 只删这个！（认证信息）
  ├── config.json        ← 你的设置
  ├── skills/           ← 你的技能 (别动)
  ├── agents/           ← 你的 agent 设定 (别动)
  └── ...

# 3. 只删 auth.json
rm ~/.config/claude/auth.json

# 或者如果它在别的地方
rm ~/Library/Application\ Support/claude/auth.json 2>/dev/null
```

### 方法二：用 find 精准定位（怕你找不到）

```bash
# 找到所有 claude 相关的 auth 文件，但只删 auth
find ~/.config -path "*/claude/*auth*" -type f -delete 2>/dev/null
find ~/Library -path "*/claude/*auth*" -type f -delete 2>/dev/null

# 确认没删错（应该只剩 skills/agents）
ls -la ~/.config/claude/
```

### 方法三：安全模式（先备份再删）

```bash
# 1. 先备份整个 claude 配置
cp -r ~/.config/claude ~/.config/claude.backup.$(date +%Y%m%d)

# 2. 查看 auth 文件在哪
file $(find ~/.config ~/Library -path "*/claude/*" -name "*auth*" 2>/dev/null)

# 3. 手动删掉看到的 auth 文件
rm /path/to/specific/auth.json
```

## 🔍 验证 skills/agents 还在不在

删完后检查：

```bash
# 应该看到你的 skills 和 agents 目录还在
ls -la ~/.config/claude/skills/
ls -la ~/.config/claude/agents/

# 如果空着，可以从备份恢复
cp -r ~/.config/claude.backup.*/skills/* ~/.config/claude/skills/ 2>/dev/null
cp -r ~/.config/claude.backup.*/agents/* ~/.config/claude/agents/ 2>/dev/null
```

## 🎯 最安全的做法（强烈推荐）

```bash
# 直接用 claude auth logout（它只删认证，不动其他）
claude auth logout

# 验证一下
ls -la ~/.config/claude/  # skills/agents 应该还在
```

**`claude auth logout` 本身就是专门只删认证信息的，不会碰你的 skills 和 agents！**

## 📝 总结

| 方法 | 命令 | 安全等级 |
|:---|:---|:---|
| 官方方式 | `claude auth logout` | ⭐⭐⭐ 最安全 |
| 手动精准 | `rm ~/.config/claude/auth.json` | ⭐⭐ 安全 |
| 备份后再删 | 先 cp 备份再删 | ⭐⭐⭐ 最稳妥 |

## 🚨 问题：你把整个 claude 目录都删了！

看这输出：
```
ls: /Users/ostensible_paradox/.config/claude/skills/: No such file or directory
```

说明整个 `~/.config/claude/` 目录都没了！不只是 auth，是整个文件夹都被干掉了！

## 🔍 为什么会这样？

你用的这个 find 命令：
```bash
find ~/.config -path "*/claude/*auth*" -type f -delete
```

**问题在哪**：
- 它匹配的是 `*/claude/*auth*`
- 如果 claude 目录结构是扁平的，没有 `*/claude/xxx/auth` 这种层级
- 可能直接把 `claude` 目录本身当匹配项给删了？

## 🆘 紧急抢救！

### 第一步：找备份

```bash
# 看看有没有自动备份
ls -la ~/.config/claude.backup.* 2>/dev/null

# 看看 Time Machine 有没有（如果你开了）
ls -la /Volumes/Time\ Machine/ 2>/dev/null

# 看看回收站（macOS）
ls -la ~/.Trash/ | grep claude
```

### 第二步：如果能找到备份

```bash
# 恢复备份
cp -r ~/.config/claude.backup.20250313 ~/.config/claude

# 检查技能还在不在
ls -la ~/.config/claude/skills/
```

### 第三步：如果没备份（用数据恢复工具）

**立即停止写入硬盘！** 马上用数据恢复工具：

1. **Disk Drill**（付费但有免费扫描）
2. **TestDisk**（命令行，免费）
3. **PhotoRec**（TestDisk 的姐妹工具）

```bash
# 安装 TestDisk
brew install testdisk

# 扫描恢复（谨慎操作）
sudo photorec
```

### 第四步：最坏情况 - 重新配置

如果恢复不了，只能从头再来：

```bash
# 创建新目录
mkdir -p ~/.config/claude/skills/
mkdir -p ~/.config/claude/agents/

# 重新登录
claude auth login

# 然后... 重新写你的 skills 和 agents
```
