## 🎯 **我想调用 o1 宝宝，该怎么办？**

o1 系列（o1-preview / o1-mini）是 OpenAI 的**推理专用模型**，和 ChatGPT 网页版是两码事。调用方式如下：

### **方式一：API 调用（推荐，最灵活）**

```python
from openai import OpenAI

client = OpenAI(api_key="你的API密钥")

response = client.chat.completions.create(
    model="o1-preview",  # 或 "o1-mini"
    messages=[
        {
            "role": "user", 
            "content": "证明：根号2是无理数"
        }
    ]
)

print(response.choices[0].message.content)
```

**关键点**[citation:9]：
- 需要 OpenAI API 密钥（付费）
- 模型名：`o1-preview`（完整版）或 `o1-mini`（轻量版）
- 上下文窗口：128K tokens
- 最大输出：o1-preview 32K tokens，o1-mini 65K tokens
- **注意**：o1 有内部"推理令牌"，虽然你看不到，但会计入费用[citation:9]

### **方式二：通过 OpenRouter（更简单）**

OpenRouter 聚合了多个模型，包括 o1-pro（o1 的企业版）[citation:6]：

```javascript
import { OpenRouter } from "@openrouter/sdk";

const openrouter = new OpenRouter({
  apiKey: "<OPENROUTER_API_KEY>"
});

const stream = await openrouter.chat.send({
  model: "openai/o1-pro",
  messages: [
    { role: "user", content: "你的数学问题" }
  ]
});
```

价格：o1-pro 输入 $150/M tokens，输出 $600/M tokens[citation:6]（贵，但强）

### **方式三：ChatGPT Plus 直接切换（最简单）**

如果你是 ChatGPT Plus 用户（$20/月），直接在模型选择器里切换：
- Web端：点模型名，选 "o1-preview" 或 "o1-mini"
- 限制：o1-preview 每周30次，o1-mini 每周50次[citation:3]
