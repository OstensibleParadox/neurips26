# Data Layout

This directory contains the data needed to regenerate the reported analyses and
to rerun the included experiment scripts under the repository's relative-path
layout.

- `compiled/`
  Aggregated CSV / JSON outputs used by paper tables, figures, and downstream
  analysis.
- `episodes/`
  Episode text files used in the semantic-closure experiment.
- `manual_web/`
  Manual packet for importing diffusion-family web outputs.
- `processing/`
  Small helper scripts for compiling or validating stored outputs.
- `raw/`
  Raw experiment outputs retained for reproduction of the current paper.

This is a paper-artifact data bundle, not a general-purpose public dataset
release.
