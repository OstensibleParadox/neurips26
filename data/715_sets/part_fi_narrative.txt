Next, I introduce a guide on correct usage of tree command. I install tree on Linux Debian/Ubuntu with sudo apt install tree, on Linux CentOS/RHEL with sudo yum install tree, on macOS Homebrew with brew install tree, and on Windows Scoop with scoop install tree or download from gnuwin32.sourceforge.net/packages/tree.htm. I execute basic tree usage: tree for the current directory, tree /path/to/directory for a specified directory. I execute tree options: -L 2 for depth limit, -a for all files, -d for directories only, -f for full path, -p for permissions, -s for size, -h for human readable size, -psh combined. I execute pattern matching: -P \"*.txt\" to include, -I \"*.log\" to exclude, tree > output.txt to output to file. I execute advanced tree: -i for inode, -J for JSON, -X for XML, -H http://example.com -o output.html for HTML, -t for time sort, -r for reverse, -s -S for size sort. I execute practical examples: tree -L 3 ~, tree -ad /var/log, tree -psh /etc > etc_tree.txt, tree -I \"*.log|*.tmp\". I check tree help with tree --help, tree --version.
