{"narrative": "I start by running 'git credential-osxkeychain erase' to clear out the old GitHub credentials from the macOS keychain. Next, I execute 'git config --global --unset credential.helper' to remove the global credential helper on this Linux/macOS setup. Then, to test the connection, I do 'git clone https://github.com/你的用户名/仓库名.git', which prompts me for new credentials. Deciding to switch to SSH, I generate a new key pair with 'ssh-keygen -t ed25519 -C \"your_email@example.com\"'. I test the SSH connection right away: 'ssh -T git@github.com'. Now I update the remote: 'git remote set-url origin git@github.com:用户名/仓库名.git', changing it from HTTPS to SSH. Just to be thorough on macOS, I open Keychain Access with 'open -a \"Keychain Access\"' to manually delete any lingering GitHub credentials. I also run 'security delete-internet-password -s github.com' to delete the GitHub internet password from the keychain. Meanwhile, I've generated a Personal Access Token in GitHub's Developer settings. To store it, I use 'git credential-osxkeychain store' for host=github.com and protocol=https in the macOS keychain. I set the default with 'git config --global credential.helper osxkeychain'. Finally, I check my SSH keys: 'ls -al ~/.ssh', and there they are—id_ed25519 and id_ed25519.pub exist."}
